# FX Lab — ローカルの戦闘演出試写室

ゲームを起動せず、基本映像1種＋追加映像最大3レイヤー＋SE1種を調整・A/B比較する開発ツールです。
本編の戦闘ルール・演出・音源・公開設定は変更しません。ビルド、クラウド、APIキー、追加のJSライブラリは不要です。

## 起動（Windows / VS Code）

VS Codeでリポジトリを開き、**リポジトリルート**のターミナルで実行します。

```powershell
python -m http.server 8000 --bind 127.0.0.1
# pythonが見つからない場合
py -m http.server 8000 --bind 127.0.0.1
```

Chrome / Edgeで **http://localhost:8000/dev/fx-lab.html** を開きます。
`http://127.0.0.1:8000/dev/fx-lab.html`でも使えます。終了はサーバーのターミナルでCtrl+C。
`file://`直開きは対象外です。localhost / 127.0.0.1 / [::1]以外のホストでは素材操作画面を無効化します。
PC 1366×768以上を目安にしています。左右の設定欄は必要に応じて欄内スクロールできます。スマホ向け操作は今回の対象外です。

## 最短の操作

1. Aの「重攻撃」などを再生し、本編の自作FX＋自作SEを基準にします。
2. Bへ切り替え、映像形式を選び、ローカルの素材を選択します。
3. 効果音を「ローカルのSEを選ぶ」に切り替え、WAV / MP3 / OGGを選択します。
4. 「再生 / 最初から」で確認。速度、サイズ、座標、透明度、音量、同期を調整します。
5. 「A → B 比較」で同じ背景・キャラクターのまま順に再生します。
6. 気に入った組み合わせをJSONに書き出します。

未購入・素材未配置の状態でも、そのまま本編の自作エフェクトと公開SEを比較できます。
「既存の公開PNGで試す」はリポジトリ同梱のKenney粒子画像を開きます。購入素材の代替だと偽って表示するものではありません。

## 映像形式と速度制御

|形式|基準速度|速度変更・停止・ループ|
|---|---|---|
|本編の自作FX|本編のCSSアニメーション時間|0.25〜2倍、Web Animations APIで制御。寿命も速度に合わせる|
|PNG静止画|静止。表示時間をmsで指定|表示サイズ等を調整。速度を変えても絵自体は動かない|
|APNG / アニメーションWebP|素材に記録された各フレーム時間|ImageDecoder対応時は合成済みフレームをCanvas再生。速度/停止/1回/ループを制御|
|同上・デコーダー非対応時|ブラウザのネイティブ再生|**速度1倍固定、内蔵ループに従う**。速度/ループ操作を無効化。停止は非表示、再実行は新しいObject URLで開始（フレーム単位の同期保証なし）|
|PNG連番|指定FPS|ファイル名の自然順（1,2,…10）で再生。0.25〜2倍|
|スプライトシート|指定FPS|列/行/使用フレーム数を指定し、左上から右、次の行へ再生。0.25〜2倍|

Chrome / Edgeのバージョン・対応コーデックによってImageDecoderの利用可否が異なります。画面下の説明を確認してください。
デコーダー非対応時に速度変更できるように見せかけません。その場合はPNG連番/シートへ変換して試してください。変換ツールは今回含みません。
アニメーションの素材内ループ回数は比較に使わず、対応時はLabのループ指定を優先します。
連番はPNGだけをまとめて選択。シートは1ファイルを選び、画像幅が列数、高さが行数で割り切れる設定にしてください。
フレーム数を行×列より少なくすれば、末尾の空きセルを除外できます。シートの余白/セル間パディングには未対応です。

- **速度**：素材の基準時間に対する倍率。0.5/0.75/1/1.5倍のボタンでも変更できます。
- **サイズ**：FXの長辺をプレビュー上のCSS pxで指定。縦横比と透過を保持。
- **X/Y**：命中先の基準点からのCSS px差分。＋Xは右、＋Yは下。
- **命中先**：ボス / プレイヤー。キャラクターは共通、ボス5体を切り替えられます。
- **透明度・回転・左右反転**：素材の描画に適用。本編の状態に影響しません。
- 静止画/ネイティブ再生は「表示時間」で試写を区切ります。静止画に速度の概念はありません。
- Canvasはブラウザの画面更新頻度で描画するため、指定FPSが画面更新より高い場合は途中フレームを飛ばして時間を維持します。

## SEと同期

WAV / MP3 / OGGをWeb Audioでデコードします。対応コーデックはブラウザに依存します。
SEはユーザーの「再生」「SEだけ試聴」等の操作から開始します。BGM・自動再生はありません。
SEの速度・音程は映像速度に連動しません。音量は再生中も調整できます。他の設定変更は停止して再試写します。

- 遅延0ms：映像と同時。
- ＋100ms：映像開始から100ms後に音。
- −100ms：音を先に出し、100ms後に映像。
- 同期範囲：−1000〜＋1000ms。Web Audioの時計へ予約し、映像側は同じ開始基準を使います。
- 「3回試聴」：設定間隔を挟んで3回。ループONでも3回で終了します。
- 「A → B 比較」：AとBを各1回。各パターンのループ指定は無視します。
- 「停止」：予約音、再生音、次回ループ、描画、残光を破棄。「再生」で最初から。
- Space：再生/停止。ただし入力欄やボタンにフォーカスがあるときはその操作を優先。

音声出力デバイスやOSの音量、機器遅延は補正しません。ミリ秒単位の音映像完全一致を保証するツールではありません。

## A/B比較

AとBは素材/SE/調整値を別々に保持します。切り替え時は停止するので重複再生しません。
背景・プレイヤー・ボスは常に共通です。「位置・速度・音量をA/Bで揃える」は**選択中のパターンから反対側へ**試写条件をコピーします。
素材とシートの行列・FPSは変更しません。ネイティブ画像側は制約を優先して1倍・ループOFFになります。
本編比較は`src/ui/combat-fx.js`の単体描画を読み取り専用で再利用し、CSSを42b7630時点から隔離したものです。
戦闘全体・スキルの複合イベント・AIは起動しません。ダメージ数字はFX Lab内の独立したプレビューです。将来本編FXのCSSが変わった場合は、隔離CSSもレビューして更新してください。

## 追加映像レイヤー／命中演出／ダメージ数値

右の設定欄で「06 素材の重ね合わせ」から追加エフェクトを最大3枚重ねられます（ベース映像と合計最大4枚）。斬撃の後で火花、さらに衝撃波を再生するなどの用途です。

- レイヤー単位：PNG / APNG / WebP、PNG連番、スプライトシートを選択し、開始遅延（0〜2000ms）、X/Y、サイズ、透明度、回転、左右反転、速度、静止画表示時間、連番FPS/シート枠数を設定できます。
- 設定はパターンA/Bごとに独立しています。再生時は重ねて表示。レイヤーごとにON/OFFと削除ができます。
- ネイティブ再生へフォールバックするAPNG/WebPは内部速度変更・フレーム単位停止を保証できません。タイミングの再現性が必要なら連番PNG/スプライトシートを推奨します。
- 「04 命中時の画面演出」ではヒットストップ、揺れ、フラッシュを、「05 ダメージ数値」では位置、サイズ、タイミング、表示時間、動き、フォント、色、縁取りを調整できます。
- 外部フォント（WOFF2/WOFF/TTF/OTF、4MiB以下）はブラウザのFile選択で読み込みます。ファイルの実体はJSONに入りません。PCの別環境や再読み込み時は再選択してください。
- 既存の本編コード・UI・SEには未反映です。本編への取り込み時は描画タイミング／命中判定との同期を別途行ってください。現在の複数レイヤーは**映像のみ**であり、SEを複数重ねる操作はありません。

## JSON保存・読み込み

「JSONを書き出す」で `設定名.fx-lab.local.json` をダウンロードします。既定でGit除外対象です。
設定名、A/BのFX/SE識別情報、速度、サイズ、座標、対象、透明度、回転、音量、遅延、ループ、間隔、FPS、シート指定を保存します。
画像・音声のバイナリ、Base64、Object URL、絶対ファイルパスは含めません。
ローカル素材の識別情報は**ベースファイル名・サイズ・更新日時**のみです（素材内容の同一性保証ではありません）。
JSONの読込後やページ再読み込み後は、ローカル素材を再選択してください。ブラウザのファイル権限を永続取得しません。
設定の永続保存はJSONだけです。選択素材や設定を勝手にlocalStorage/IndexedDBへ保存しません。

- スキーマ：`keisei.fx-lab`、version 1。
- `scene`：共有するボスID。
- `patterns.A/B.visual`：builtinのID/強度、またはlocalの形式/ファイル識別情報。
- `patterns.A/B.sound`：builtinのID、localのファイル識別情報、またはnone。
- `patterns.A/B.playback`：表示・時間設定。`size/x/y`はCSS px、`speed`は倍率、`audioDelayMs/gapMs/holdMs`はms。
- `core.js`はDOM非依存。将来のエンジンでは、素材IDの解決と描画/音声アダプターを置き換えて利用できます。
- 任意URLをJSONから取得しません。知らない項目を除去し、形式/数値範囲を検証します。
- `fx-lab/example.json`は公開素材だけの設定例です。


## 命中演出・ダメージ数値・追加レイヤー（試験実装）

「04 命中時の画面演出」からヒットタイミング、ヒットストップ、揺れの強さと時間、フラッシュの強さと時間をA/B別に調整できます。
「05 ダメージ数値」ではプレビュー値、表示ON/OFF、X/Y、文字サイズ、命中からの遅延、表示時間、アニメーション（ポップ・上昇・静止）、色、縁取り、フォントを調整します。
標準4種類のフォントに加えて、WOFF2 / WOFF / TTF / OTF（最大4MiB）をPCから読み込めます。JSONはフォントの識別情報だけを保存し、フォントのファイル本体は含みません。復元時には再選択が必要です。

「06 素材の重ね合わせ」では、元のFXとは別に最大3つの映像レイヤーを追加できます。対応形式はPNG/APNG/WebP、PNG連番、スプライトシートです。
レイヤーごとに有効/無効、開始遅延、位置、サイズ、速度、透明度、回転、左右反転、FPS等を調整します。A/B設定には別々のレイヤー構成を保存します。
**追加レイヤーにSEは付与できません。音声は現在1つのままです。**
**複数レイヤー編集は初期実装で、ブラウザ実機の動作・音と映像の一致・実際の有料素材ではまだ検証できていません。**
APNG/WebPでフレーム展開できない場合はネイティブ再生となり、レイヤー単位の再生速度・ヒットストップを厳密に制御できません。精密な演出調整にはPNG連番またはシートを推奨します。
命中演出のJSONは`patterns.A/B.playback.impact`、追加レイヤーは`patterns.A/B.layers`に保持されます。旧v1 JSONもデフォルト値を補って読み込めます。
本編側の戦闘描画にはまだ反映しません。本編へ取り込むときは再生処理の調整・検証が別途必要です。

## 有料素材の保護

- ファイル選択でPC上の素材を開く方式を推奨します。リポジトリへコピーする必要はありません。
- コピーする場合はルートの `private-assets/vfx/`、`private-assets/sfx/` に置きます。`private-assets/` 全体は `.gitignore` 登録済みです。
- `git add -f`で除外を解除しないでください。素材/音声/購入ZIPをコミットしないでください。
- `.gitignore`は既に追跡済みのファイルを解除しません。今回private-assetsに追跡ファイルがないことを確認しています。
- ツールは素材を外部送信しません。ファイルはブラウザのメモリとObject URLで扱い、画像/SE/JSONのアップロード先を持ちません。
- CSPで外部スクリプト/通信/フォーム送信を制限し、公開ホストではツール画面を無効化します。
- Pythonサーバーは `--bind 127.0.0.1` で起動し、ポート公開やGitHub Pagesへの素材配置は不要です。
- 設定JSONにも素材のファイル名は入ります。外部共有時はその情報も確認してください。
- 今回、AG Studio / The Sound Guildの購入素材は未受領・未試験です。付属ライセンスの利用条件は購入後に確認してください。

## 制約と構成

各ファイル最大64MiB、フレーム展開/連番は最大300フレーム、展開画像合計32Mピクセル（ビットマップだけで最大約128MiB）。デコーダー/ブラウザ/GPUの追加メモリは別です。ネイティブ再生の内部フレーム数・デコードメモリはブラウザ管理で、この展開上限では管理できません。
大きな素材は短い連番に分割してください。サイズ超過・未対応・破損は画面内でエラー表示します。
SVG/GIF/動画、音声多重レイヤー、高度なタイムライン、APNG変換、素材の自動検索/フォルダー監視、購入素材のパスによる自動再読込は対象外です。
読込処理はバックグラウンドで完了する場合がありますが、素材切替後の古い結果は破棄し、停止後に勝手に再生しません。

|ファイル|役割|
|---|---|
|`dev/fx-lab.html`|単一画面の入口|
|`dev/fx-lab/core.js`|設定検証・時間計算・自然順ソート。DOMなし|
|`dev/fx-lab/media.js`|ローカル画像/音声デコードとメモリ解放|
|`dev/fx-lab/lab.js`|UI、描画、同期、A/B、JSON入出力|
|`dev/fx-lab/lab.css`|試写室レイアウト|
|`dev/fx-lab/reference-fx.css`|本編自作FXの隔離CSS（42b7630基準）|

開発用の検証は `npm test`、`npm run check`。追加のブラウザ試験手順・結果は[レポート](../reports/fx-lab/REPORT.md)を参照してください。
Windows実機・Edge実機・聴感評価は別途必要です。Linux Chromiumのデコード成功を音質評価と混同しないでください。
