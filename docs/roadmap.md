## 作業の進め方

1. 最新のユーザー指示で対象・非変更範囲・受け入れ条件を確定する。
2. 作業ブランチ・既存変更を確認し、指示されていない退避・巻き戻しをしない。
3. 小さく検証可能な差分で実装し、`npm test`と`npm run check`を実行。
4. UI変更では必要なブラウザ検証を加え、実機で未確認の部分を報告する。
5. 仕様と進捗を更新し、ユーザーの指示がある場合にコミット・プッシュする。
