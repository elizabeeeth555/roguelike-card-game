# 02. 第一紀の戦闘ルール（Codex実装用）

「確定」「検証採用」の背景は[確認済み事項](../../first-era-decisions.md)を参照。ここには、未確定の処理境界を含めた**実装用の統一解釈**も明記する。実装時にはユニットテストで境界を固定すること。

## 1. 戦闘の基礎

- プレイヤー・ボスの**最大HPは双方20、開始時20/20**。
- **プレイヤー先攻**、そのあとボス後攻。双方の自ターンが1回ずつ終わって1ラウンド。
- 標準決着**4ラウンド前後、目安3〜5ラウンド**。単純な平均でなく、先攻有利とプリセットごとの勝率も測る。決着目標は強制ターン制限ではない。
- 通常手札は毎ターン引き直さない。最大5枚の固定手札で、**各スキルは自ターンに最大1回**（未使用・CD・条件・マナが許す場合）。使用済み状態は次の自ターンでクリア。
- HP0以下で即時勝敗確定。生存者の残行動や毒処理を継続しない。同時死亡の特別ルールは今回のスキルからは通常発生しない。
- 第一紀の効果数値は**記載値そのまま（世代倍率×1）**。攻撃力ステータスは無し。世代倍率の一般化（×1→×10→×200→×6000→×240000）は将来用の設計メモのみ。

## 2. マナと先攻補正

| 項目 | 新仕様 |
|---|---|
| マナ上限 | 戦闘開始時は双方3。常設の上限増加は最大5。 |
| プレイヤーの第1自ターン | **利用可能2／上限3（表示`2 / 3`）**。先攻ペナルティ。 |
| 後攻ボスの第1自ターン | **利用可能3／上限3（表示`3 / 3`）**。 |
| 第2自ターン以降 | 自ターン開始時、現在の上限まで補充。持ち越し不可。 |
| マナ加速共通アクション | 当自ターンに2マナ消費、**次の自ターン開始時から**上限+1（3→4→5）。 |
| 加速制限 | 各自ターン最大1回・上限5未満・使用可能マナ2以上。通常スキル枠は使わない。 |
| 先後手の扱い | 順番は戦闘中固定。将来ボス先攻になっても、**先攻者**の初手だけ2/3を適用可能なデータ構造にする。 |

- R1先攻2/3で加速→残り0/3、R2開始時4/4。R2再加速→残り2/4、R3開始時5/5。
- 旧「ラウンドに応じ自動増加」と「旧ボスの初手2マナ」は廃止。
- マナ減少は**その自ターンの使用可能マナ**から引き、上限そのものを下げない。確認済みの処理順：予約された上限増加を反映→新しい上限まで補充→当ターンに有効なマナ妨害を減算（最低2）→行動開始。例えば上限3への妨害−2は開始時2/3。
- 上限に達しても未使用のマナ加速を表示するが、ボタンは無効にして理由を示す。

## 3. スキル再使用（自分のターン基準）

| スキルの表記 | 使用した自ターンR | R+1 | R+2 | R+3 |
|---|---|---|---|---|
| `なし（CD0）` | 使用済み | 使用可 | 使用可 | 使用可 |
| `CD1` | 使用済み | **使用不可** | 使用可 | 使用可 |
| `CD2` | 使用済み | **使用不可** | **使用不可** | 使用可 |
| `戦闘1回` | 使用済み | 使用不可 | 使用不可 | 使用不可 |

- Rは**使用者本人の自ターン番号**。敵ターンの間にCDを進めない。
- クールタイム中はスキルを固定手札から消さず、暗転・`残り1`/`残り2`と再使用可能時期を表示。
- スキルを使った自ターンはコストが戻っても再使用不可。
- 行動ボタン連打・非同期演出中の重複発動防止が必要。

## 4. バリア（ユーザー確定の「1ターン」を実装用に明文化）

- `結界`：コスト1、**バリア3**。`堅守`：コスト2、**バリア5**。
- **バリアの寿命は、付与者の直後に来る相手ターンの終了時まで**（その相手ターン中の攻撃を守る）。相手が攻撃しなくても終了時に残量を消去。
- 同ターン中に付与したバリアは加算できるが、**同じ相手ターン終了時に残量をまとめて消す**。
- ダメージを受ける際はバリアを先に減らし、残りをHPへ（特記の「バリア無視」は例外）。バリア上限は今回設けない。
- スキル詳細テキストに、例：`バリア3を得る。次の相手ターン終了時に残りのバリアは消滅する。` と明記する。
- これは確認済みの「基本1ターンのみ」の処理境界。将来の相手ターン中防御や複数持続バリアを追加するときは別仕様に拡張。

## 5. 毒カウンター

- 対象ごとに**整数0〜4**、上限4。毒付与は加算し4で切り捨て。
- **対象自身のターン終了時**、その瞬間のカウンター値`n`だけ**HPへ直接ダメージ**（バリア無視）。その後カウンター`n-1`へ（最低0）。
- 例：毒3が追加付与されなければ、対象自身のターン終了ごとに3→2→1（合計6ダメージ）。
- 毒0の対象へはtickなし。
- `毒刃`・`蝕心`の**対象条件は毒カウンター1以上**。スキル使用直前に判定。毒がなければマナ消費もCD付与もしない。
- `毒刃`：毒カウンター`n`を**使用時に参照**、ダメージ`2+min(4, 2n)`を通常の攻撃として解決、その後毒−1。
- `蝕心`：毒カウンター`n`を**使用時に参照**、ダメージ`n`を通常の攻撃として解決、その後毒−1。
- 上記2枚の直接ダメージは**バリアで防げる**。毒系効果でバリアを無視するのはターン終了時の毒tick。環境ダメージの消耗も別途バリアを無視する。
- `腐蝕`、`疫病`は毒を付与する効果であり、それ自体の即時ダメージはない。
- 行動中の直接ダメージで相手HPが0になれば即決着し、毒消費演出など後続の処理は残さない（状態後片付けは内部整合を保つ）。

## 6. 妨害の重複と寿命

- **重複可（確定）**。例えば`牽制`（次の攻撃−2）と毒状態時の`呪詛`（次の攻撃−2）が重なれば、対象の次の攻撃スキル1枚に−4を適用。
- 弱体は対象が**次に使用する攻撃スキル1枚**の与ダメージから合計を引き、その時点で消費。バリア計算の前に合計ダメージを最低0へ丸める。
- **確認済み仕様**：対象がそのターン攻撃しなければ、弱体は次の攻撃が行われるまで保持。「次の攻撃」という文言を優先。スキル効果や戦闘UIの説明にも寿命を表記。
- `封脈`：対象の**次の自ターン開始時の使用可能マナ**を−1（複数回付いたら合算）。最低2を維持し、そのターンの開始時にすべて消費。マナ上限は減らさない。
- 敵・プレイヤーとも同じルールを使う。次の自ターンが来る前に戦闘終了したら残りは消滅。
- **確認済み仕様**：マナ減少の最低2はマナの初期上限や先攻補正と矛盾しないよう制限。今後の別能力で通常上限が2未満になる場合は別途設計。

## 7. 一時攻撃強化とコンボ判定

- `戦意`：その自ターン、**このスキルの後に使用する最初の攻撃スキル**にダメージ+3。該当スキルなしでターンを終えたら失効。CD2。
- `布石`：使用した次の**自ターンに使う最初の攻撃スキル**にダメージ+2。次の自ターンで攻撃せずに終えたら失効。CD1。
- **確認済み仕様**：戦意と布石が同じ攻撃に適用されると、+3と+2は加算。攻撃の固定追加値は第一紀×1の値。
- `疾走斬`：自ターン中の**最初の攻撃スキル**として使用したとき合計3、そうでなければ1。
- `追撃`：自ターンで**別の攻撃スキルをすでに使用**していれば合計3、そうでなければ1。追撃の自身の使用は事前条件のカウントに含めない。
- `切り込み`：使用する直前に対象HPが**最大HPの半分以下（20ならHP10以下）**であれば合計4、そうでなければ2。今回の合意値は**4**で統一。
- 攻撃カテゴリは実装上のスキルタグで判定。**今回の確認済み仕様は「即時ダメージを与えるスキルは攻撃タグあり」**。対象スキルの完全一覧は`03`を参照。UIで攻撃系と妨害系の両方のタグを示せるようにする。
- ダメージ数値の算出順（実装用統一）：スキル基本値→条件ボーナス→戦意／布石の加算→敵の攻撃弱体の減算（最低0）→バリアで吸収→実HPダメージ。割合・複数攻撃は今回の19種に含まれない。

## 8. ターン終了の順番（テスト必須）

1. 自ターンのスキル／加速／ターン終了操作を確定し、二重操作をロック。
2. `戦意`などの「このターン限定」の未消費バフを失効させる。
3. **ターンを終了する本人**に毒tick（現在値のHP直接ダメージ）を適用 → 直後に毒−1。
4. 毒でHP0なら即決着。
5. **そのターン中に相手が前ターンまでに付与したバリア**の残量を消去する（例：プレイヤーターン終了でボスのバリアを破棄）。
6. ラウンド／行動者を更新し、次の行動者の自ターン開始で消耗→致死判定→マナ補充・加速の予約反映・マナ妨害を適用。CDの使用可否は自ターン通算番号で判定。
7. 処理結果をログとUIに反映。勝敗成立後は行動できない。

**重要**：毒を持つプレイヤーが自ターンを終了すると、その時点で毒を受ける。ボスの自ターン終了時はボスが毒を受ける。旧版の「敵ターン開始に毒」は使用しない。

## 9. ログとテスト向けデータ

- 全スキルの**使用前条件／使用後HP／マナ／バリア／毒／弱体／CD**の変化をテストから参照できる形に。
- バランス検証では、乱数（ボスプリセット抽選・報酬候補）を注入または固定シードで再現できると望ましい。
- UIに「使用不可の理由：マナ不足／CD／発動条件未達／当ターン使用済」を表示。AIの不正使用も同一の判定関数で防ぐ。
- **最適行動は期待目標であって数理的な証明ではない**。AIは決定的に同じ入力から同じ行動を選ぶようにする。

## 10. 正式採用：消耗ダメージと防御CD

結界・堅守はCD1。他17枚のCD/コスト/効果と毒終了時処理は維持。
12R以降、各自ターン開始時に環境ダメージ `1+floor((R-12)/2)` をHPへ直接適用（11R以前0）。12/13R=1、14/15R=2、16/17R=3、以後2Rごと+1。両側同じRの量で、バリア無視。
開始順は消耗→HP0なら即勝敗確定→予約加速/補充/妨害/予約バフ等→通常行動。前ターン終了毒・バリア期限の処理は従来通り先に終える。
通常攻撃/毒/反撃とは別の `environmentDamage` / `kind:exhaustion`。通常被弾特性へ暗黙接続しない。AIも同じ遷移を使う。強制ラウンド終了は設けない。
