# スキル構築型ローグライクRPG：戦闘UI

2026-11-07。今回のUI指示は過去のカード型UI仕様より優先する。

最新の宣言・敵行動テンポ・文字サイズは[14-tempo-readability](14-tempo-readability.md)。
最新の選択位置・交換UIは[13-combat-presentation](13-combat-presentation.md)で更新。

- 表示用語はスキル/スキル習得/スキルセット/継承スキル。内部のcard/deck、DOM ID、ファイル名、19種の効果データは互換性のため維持し、表示時に用語変換する。歴史資料と研究は変更しない。
- パネル左上は名前、右上は♦とMP、中央は効果概要、右下は⌛と基本CD。CD0も表示。分類は通常表示を整理し、狭いパネルの名前は折返し、効果は省略して詳細で全文確認。
- 状態は使用した自ターンだけ「使用済」、以後は残CDがあれば「CD中（残nT）」を単一の中央表示。使用済とCD中は排他。残CDの計算は既存の所有者自ターン基準を維持。
- 戦闘詳細は効果全文だけ。自分の使用ボタンは既存合法判定で無効化し、敵に使用ボタンは付けない。予測計算とHPバー予測は残すが、詳細内の状態/予測/メタ文章を除く。
- 敵パネルは選択でも位置/倍率を固定。詳細領域だけ左右8pxの余白内へ補正。自分もパネルを固定し、詳細/使用ボタンだけ補正する（13参照）。
- ダメージは赤の−n、回復は緑の＋n。ハートなし。敵は上、プレイヤーは下に分け、一つの表示ノードを再利用して連続表示を重ねない。バリア減少は⬡で区別。数値演出はスコープ内のリセット処理で破棄する。
- BATTLE START（通常450ms/高速300ms）→消去→空白（60/40ms）→YOUR TURN（350/230ms）。再戦も同じ順序。ターン交代は通常350ms/高速230ms。演出・空白中は操作不可。リセットは待機解除と世代識別で残留を防ぐ。
- 青YOUR TURN/赤ENEMY TURN、開始は金系。常時表示も小さな枠で強調。音量→設定の順。顔はPC50px/スマホ44px、縦横比を保持。PCのHUDはスキル領域上端に揃え下方向への拡張を許す。スマホの基本縦配置は維持。
- 毒は紫の文字アイコン/枠。MPは♦系で統一。画像素材追加なし。
- 習得詳細は名前/効果全文/閉じる/習得または入れ替えだけ。リロールとスキップは通常習得画面に残す。5イベント・2リロール・入れ替え/取消・スキップの処理は不変。

AI-2/消耗/D案、MP・効果・CD・毒・バリア・加速・上限5・ボス構成は変更しない。未実装特性/継承6枠目は追加しない。
