# 05. 新戦闘UI：立ち絵・奥行き・将来スロットを含む画面仕様

**レイアウト方向はユーザーと合意**。PCでは旧案「左に敵／右に英雄」を使わない。**手前左下に英雄の後ろ姿、奥の右上に敵の全身正面**という、遠近のあるコマンドRPG風の対峙構図へ変更する。

## 1. UIの優先順位

1. **戦闘の操作**：現在マナ／上限、HP、手札5枚、マナ加速、ターン終了、カード使用不可理由。
2. **状態と意思決定**：バリア残量と期限、毒カウンター、攻撃弱化、マナ妨害、攻撃バフ、CD残、自他デッキ。
3. **演出**：キャラ立ち絵、ダメージ表示、カードカットイン、状態異常、敵カードの実発動表示、BGM/SE。
4. **将来予約（今回必須）**：**通常5枚とは別の継承1枠／ボス固有能力アイコン／プレイヤーパッシブアイコン**。
5. **将来予約（今回は省略可）**：枷、独立した必殺技。これらは使えるように見せないこと。

## 2. PC：奥行きのある新配置（1366×768等）

```text
┌──────────────────────────────────────────────────────────────────┐
│ 第一紀 / BOSS BATTLE                             ♫  🔊  ⚙   │
├──────────────────────────────────────────────────────────────────┤
│ ROUND 1 / YOUR TURN                         [敵 HP 20/20]        │
│                                                [敵 MP 3/3]      │
│                                     [ボス固有◆] [状態異常]      │
│                                 ┌───────────────────────┐        │
│                   奥行き・遠景 →│ ボス正面全身（右上奥）│        │
│                                 └───────────────────────┘        │
│                                                                  │
│          戦闘エフェクト・カード発動・ダメージ数値                │
│                                                                  │
│ ┌──────────────────────┐                                         │
│ │ 英雄斜め後ろ姿       │← 手前（ボスより大きく見せてもよい）     │
│ │ 右上奥を向く         │                                         │
│ └──────────────────────┘  [自 HP20/20 MP2/3] [パッシブ◇]       │
│ [敵デッキ確認] [戦闘ログ] [状態詳細]                              │
├──────────────────────────────────────────────────────────────────┤
│ [マナ加速（2）]    [自マナ 2/3]                [ターン終了]       │
│ [通常1][通常2][通常3][通常4][通常5]  ║ [継承1枠🔒 未解放]      │
└──────────────────────────────────────────────────────────────────┘
```

- 奥行きは**CSSの重なり・サイズ差・斜め配置・背景演出**で表現。3Dモデルや移動可能な3Dカメラは必要ない。
- 英雄の後ろ姿は**左下の手前**、ボスは**右上の奥**。中央にカード・攻撃エフェクトの空間を残す。
- HP／マナ／固有能力／パッシブは立ち絵に隠さない。カメラ演出中も操作・判断情報が読めること。
- 遠近感のため英雄の表示サイズを大きく、ボスをやや小さくしてもよい。立ち絵は切れすぎないよう`object-fit: contain`等で調整。
- 手札・マナ加速・ターン終了は戦闘画面の**下部操作帯に集中**。継承枠は通常5枚の右に区切って表示。
- 敵デッキ5枚は閲覧可能。実際の次アクションの順序・選択は非公開。
- PCでアイコンに**マウスオーバー**したらポップアップ。クリック・キーボードフォーカスでも説明閲覧可能。

## 3. スマホ：縦画面（360〜430px、390×844を基準）

```text
┌────────────────────────────────┐
│ 第一紀          音 / 設定     │
│ 敵 HP 20/20   MP3/3 [固有◆]  │
│ 状態：毒 / バリア / 弱化      │
│                  [ボス全身]  │
│ [敵デッキを見る]             │
├────────────────────────────────┤
│ ROUND 1 / YOUR TURN            │
│ 戦闘演出・短いログ             │
│ [詳細ログ]                     │
├────────────────────────────────┤
│ [英雄斜め後ろ姿] 自 HP20/20   │
│                  自 MP2/3     │
│                 [パッシブ◇]  │
│ 状態：毒 / バリア / 弱化      │
├────────────────────────────────┤
│ [マナ加速(2)] [ターン終了]    │
│ [1][2][3][4][5] 通常手札     │
│ [継承専用 🔒 未解放]          │
└────────────────────────────────┘
```

- スマホでは敵上・自分下。**左下英雄、右上敵**の斜め関係をできる限り残すが、操作帯の可読性を優先。
- 狭い端末では、**手札・マナ加速・ターン終了が常に押せる**ことを優先して立ち絵を縮小。必要なら操作帯を画面下部に固定し、バトルフィールドをスクロール可能にする。
- 5枚のカードを横並びで常時認識できるようにし、カード詳細は**タップで拡大→使用確認**の二段階。画面を覆う説明は閉じられること。
- ログは折りたたみ／オーバーレイ表示で、開いても画面が際限なく縦に伸びない。
- ポップアップは**スマホタップで開閉**、閉じる操作や他領域タップでも閉じられる。hoverだけに依存しない。
- テスト対象：幅360×高さ800、390×844、430×932程度。PCは1366×768以上。

## 4. 三つの**必須**将来予約枠

| 要素 | 本版の表示 | 使用動作 | 将来の想定 |
|---|---|---|---|
| **継承専用カード枠** | 通常5枚と区切った`🔒 0/1 未解放` | **使用不可**。詳細は「第二紀以降の実装時に解放予定」 | 1枚分の独立カード。通常5枚の上限に含めない |
| **ボス固有能力アイコン** | ボス情報付近に`固有 ◆`、灰色 | **発動処理はない**。ホバー／タップで「この第一紀デモでは能力未設定」 | 能力名、効果、発動時点、継続／回数を表示 |
| **プレイヤーパッシブアイコン** | プレイヤー情報付近に`パッシブ ◇`、灰色 | **発動処理はない**。ホバー／タップで「未取得／今回未実装」 | 取得済み能力の名称・効果・条件を一覧化 |

- **ボスに架空の固有能力を発動させたり、パッシブを勝手に付与したりしないこと。**
- 追加予定の「枷」「必殺技」は同じアイコン列や別スロットに拡張できる余白を確保してもよいが、**今回の実装必須3項目より優先しない**。
- 仕様上の「継承の仕組み」は今回オフ。継承枠が使えないことと、将来のためのUI枠があることは矛盾しない。

## 5. 固定カード表示と使用できない理由

| 状態 | 常時表示・フィードバック |
|---|---|
| 使用可能 | コスト数字・カード名・種類アイコン・通常の枠色 |
| そのターン使用済み | 暗転／`使用済み` |
| CD中 | 暗転／`CDあとN自ターン`・詳細表示で使用可能時期 |
| マナ不足 | 暗転／`マナ不足`、必要コストを表示 |
| 毒刃／蝕心の条件未達 | 暗転／`対象が毒状態の時のみ` |
| マナ加速使用済み | ボタン非活性／`このターン使用済み` |
| 最大マナ5 | ボタン非活性／`上限到達` |
| 戦闘演出中 | 無効にして二重入力を防ぐ。ただし演出スキップや設定は安全に操作できる |

- マナ表示は必ず`現在/最大`（例`2/3`, `4/4`）にする。
- ダメージは印字固定値と条件付き効果から算出し、旧攻撃力ステータスは表示しない。
- 一時強化・マナ妨害・攻撃弱化・毒カウンター・バリアを**数値・アイコン・説明文**で表示。色だけを頼りにしない。
- 条件付きの「疾走斬」「追撃」「切り込み」では、カード詳細で条件が現在成立しているか分かると望ましい（見えている相手HPと使用順から判断可能）。
- バリアカードの文面には**次の相手ターン終了時に残りが消える**ことを記載する。

## 6. 立ち絵と演出

- 配置する画像は `assets/characters/<id>_boss.png`、`_face.png`、`_back.png`（採用4人×3種）。画像の対応は`06-assets-and-characters.md`。
- **背景は別レイヤー**、キャラは透過PNGを重ねる。プレイヤー・ボスは後から差し替えできるようにする。
- 攻撃：プレイヤーが少し前進／敵が揺れる。ガード：盾の光、毒：紫色の粒子、マナ加速：上限が光る。被弾時HPバー減少と数値演出を同期させる。
- 立ち絵への過剰なカメラ揺れ、長すぎる単独カード演出は避ける。**派手さより手札の操作快適性を優先**。
- 既存の`YOUR TURN`／`ENEMY TURN`約3秒の演出、クリック・タップ・Enter/Spaceでのスキップ、高速表示、開閉ログ、BGM/SE ON/OFF、音量を維持。可能なら旧SEを流用。
- 画像が欠けていても代替アイコンで描画・戦闘できる。画像ロード失敗でUIや戦闘処理を停止させない。
- キャラ絵は**仮素材**。元のBOOTH素材は今回未同梱。

## 7. 推奨コンポーネント構造（実装裁量）

- **戦闘状態ビュー**：HP／マナ／毒／バリア／弱体／持続を描画。
- **キャラクタービュー**：画像表示とボス・プレイヤーID。将来の同一キャラのボス化を考慮。
- **アビリティアイコン列**：能力リストに応じて描画、ポップオーバーを共通化。今回は空アイコンを描画。
- **固定手札＋継承枠**：カードIDをキーとする。継承1枠は通常カードとは別DOM領域。
- **カード詳細**：PCホバー／クリック、スマホタップ、キーボードフォーカス、使用可否と条件。
- **ログ・演出**：実際に適用した効果を参照。演出タイマーが勝敗・再挑戦後に持ち越されないようにする。

## 8. 画面受け入れ条件

1. PCで左下手前英雄の**背中**、右上奥敵の**全身**が確認できる。旧左右配置に戻さない。
2. スマホで両キャラ・手札5枚・加速・ターン終了・HP・マナが利用可能。
3. **継承枠・ボス固有・プレイヤーパッシブが常に見える**。未解放・未実装の説明が正しい。
4. 固有／パッシブ説明はPCホバー・キーボードフォーカス・スマホタップで読める。
5. CD・毒条件・マナ不足でカードを誤使用できない。状態表示と内部判定が一致。
6. 画像やBGMが読み込めない時でもゲーム進行・再挑戦できる。

## 9. 実装前の確認結果

攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合カードは攻撃色と文字タグを併記。大男・斥候は画像を設定せず代替表示、他4人の12PNGを正式配置する。元の受領素材にあったプレビュー・設定シートは実行時に不要のため保持しない。
