# 04. 第一紀の進行と固定ボスデッキ

## 1. 進行（確定）

```text
ゲーム開始
  ↓
初期デッキ2枚を選択（現版はビルド選択式）
  ↓
カード獲得イベント1：未所持19種から3択→1枚獲得（3枚に）
  ↓
カード獲得イベント2：未所持19種から3択→1枚獲得（4枚に）
  ↓
カード獲得イベント3：未所持19種から3択→1枚獲得（5枚に）
  ↓
第一紀ボス：固定5枚の5プリセットのうちランダムに1つ
  ↓
勝利 or 敗北 → 結果画面 → 再挑戦
```

- **カード獲得3回のみ**。旧版の強化・特殊強化・切り札・分岐イベントは出さない。
- 既存デッキとの**同一カードID重複禁止**。3択内にも同IDを並べない。
- 3回終了時は必ず通常5枚。取得見送りは今回の正規導線には不要。旧コードの上限5での入替は将来用に保持してもよいが今回は発生しない。
- 19種類すべてから報酬抽選（A〜D限定）。毒参照カードのようなシナジー依存カードにも、現段階では追加の取得制限を設けない。**成り立たない組合せが発生したらテストで記録し、勝手に補正しない**。
- ユーザーは将来初期デッキをなくしたい。今回は**検証しやすさ優先で2枚**を維持。

## 2. 初期ビルド候補（確認済み）

初期2枚と、以下の3つの組合せを今回の検証版に採用することをユーザー確認済み。

| 名前 | 最初の2枚 | 狙い |
|---|---|---|
| 速攻 | 斬撃＋疾走斬 | 初手2マナで複数枚使用できる。攻撃順が分かりやすい |
| 中速 | 重斬＋牽制 | 火力か妨害かを初手から選ぶ |
| 毒 | 腐蝕＋斬撃 | 毒を仕込むか、直接攻撃するかの選択 |

各候補は同名重複なし。出現カードは19種の共通プールに含む。

## 3. 固定5枚ボスデッキ：全5パターン（委任選定）

**戦闘開始時に以下の5つから1プリセットをランダムに選出**する。抽選は**プリセット単位**で、カード5枚の個別ランダム抽選ではない。カード重複なし。今回の敵は第一紀なので強化／継承効果なし。

| プリセットID | 立ち絵 | 戦術 | 固定5枚 |
|---|---|---|---|
| `boss_knight_defense` | 02 重装騎士 | 防御・反撃的テンポ | **斬撃 / 重斬 / 結界 / 堅守 / 牽制** |
| `boss_witch_poison` | 03 魔女 | 毒付与・毒消費 | **腐蝕 / 疫病 / 毒刃 / 蝕心 / 呪詛** |
| `boss_giant_power` | 04 大男 | 重い攻撃・維持力 | **重斬 / 大振り / 猛進 / 結界 / 手当** |
| `boss_scout_rush` | 05 斥候 | 初動と追撃、後半切り込み | **疾走斬 / 追撃 / 切り込み / 結界 / 手当** |
| `boss_sage_tempo` | 06 老魔導士 | 攻撃強化・マナ妨害 | **戦意 / 封脈 / 布石 / 呪詛 / 斬撃** |

**設計理由**：デッキに単独で使えない毒刃／蝕心だけが入る事故を避け、毒型には付与源を入れた。速攻は攻撃3枚のCD1により毎ターン最大火力が出るわけではない。重装騎士はバリアに投資すると火力が下がる。全19種類が5プリセットのいずれかには登場する。

### 戦術を検証するときの注目点

- **重装騎士**：バリアの張りすぎで攻撃不足にならないか。
- **魔女**：毒カウンター消費の順序を誤らず、毒tickを優先すべきか判断できるか。
- **大男**：3コストの大振りだけを毎ターン撃つのが最適にならないか、加速投資と比較できるか。
- **斥候**：R1先攻プレイヤー2マナに対して敵の短期火力が高すぎないか。
- **老魔導士**：戦意＋攻撃コンボとマナ妨害の判断、条件を無駄にしないか。

## 4. ボスのキャラクター画像（確認済み）

- 第一紀デモのプレイヤーは黒剣士（01）固定。敵の割当は表のとおり。大男・斥候の画像は使わず、代替表示する。キャラ選択画面は追加しない。
- `*_boss.png`（敵の全身）、`*_face.png`（会話／カットイン）、`*_back.png`（プレイヤーの斜め後ろ姿）。
- 将来は**どのキャラでもプレイヤー時とボス時に同一キャラクターIDの別ポーズを使う**。画像とデッキをデータ上で一体化しすぎないこと。
- ボス固定カード構成とキャラクターの一対一対応は今回の検証用であり、将来の継承システムでは「前の自分のカード構成を次ボスに引き継ぐ」を優先する。

## 5. ボスAI：ランダムに行動しない（確定方向）

- ランダムは**戦闘開始時のプリセット抽選**だけ。敵ターン内のカード・加速・順番選びにはランダム行動を混ぜない。
- 現在マナ、最大マナ、上限成長、自ターンの使用済みカード、CD、毒条件、HP20、相手と自分のバリア、次の攻撃弱化、布石・戦意などの条件を踏まえる。
- **カードの順序が重要**：戦意→攻撃、疾走斬→追撃、毒付与→毒刃など、実行可能な**順序付きの候補列**を評価。攻撃の前後を入れ替えてはならない。
- **マナ加速も選択肢に含める**。2マナを払ったターンの攻撃・防御損失と、次自ターン以降の上限増加を比較する。
- ターン内の全候補はカード5枚＋共通行動1回程度のため、合法手を列挙して評価する方法が現実的。各候補がHP・状態変化に与える影響を計算できる構造を推奨。
- 最低でも**目前の勝利・目前の敗北回避を最優先**。次に実HPダメージ・毒期待値・防御の実効値・弱化／マナ妨害・次ターンの展開余地を評価する。加速を常時最優先にしない。
- **同じ入力なら同じ手順になる**よう固定タイブレークを採用。数学的な真の完全最適を保証する必要はないが、明白な悪手が出ないようテストする。
- **不正な先読み禁止**：未抽選の将来報酬、プレイヤーがまだ選んでいない行動、乱数の未来値を参照しない。公開されているプレイヤーデッキと現在の状態を考慮するのは可。
- 敵の「使用予定カード」を発動済み演出に表示しない。ログと演出は実際の発動に同期。

## 6. バランスの現時点の位置づけ

受領時点の5プリセットは未測定だったが、実装後に固定シード150対戦で観察した。[実測結果](../../first-era-architecture.md#2026-11-06の検証結果)を参照。正式なバランスが確定したものではない。プレイヤーの先攻初回2マナと敵後攻3マナで相性差が大きくなる可能性がある。数値変更が必要な場合は実測値とカード変更案を示し、ユーザー承認後に調整する。

## 7. 転記防止用データ

`tests/fixtures/first-era-bosses.json`に**カードIDベースの固定デッキ5種類**を収録。19種すべてがどれかのプリセットに含まれることをパッケージ作成時に確認済み。初期2枚の確認済み定義は `src/game/card-data.js` の `STARTERS`。

## 8. 結果と再挑戦（確認済み）

勝敗どちらにも「同じ条件で再戦」と「最初から」の2ボタンを表示する。同条件再戦は自分の5枚・ボスプリセットを維持し、HP・マナ・CD・状態異常を初期化。最初からは初期ビルド選択へ戻り、次のボス戦開始時にプリセットを再抽選する。
