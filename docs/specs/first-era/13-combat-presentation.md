# 第一紀：戦闘テンポ・交換・演出（2026-11-07）

本書は12-skill-uiの演出時間と選択位置の記述を更新する。ルール/19スキル/AI-2/抽選は不変。

## 操作と表示

- 敵味方とも選択パネルの位置/倍率を固定。効果詳細と使用ボタンだけを画面内8pxへ補正する。2段階使用は維持。
- 交換候補に名前/MP/基本CD/概要。パネルで効果全文を確認し、独立した「このスキルと交換」で確定。候補習得詳細の導線は「このスキルを選択」。
- 交換時はリロール/スキップを隠し、独立したキャンセルで同じ候補/残数/進行へ戻る。通常習得画面は既存通り。
- 戦闘終了後の操作不可理由は「戦闘終了」を「演出中」より優先する。

## 時間（通常 / 高速、ms）

|項目|通常|高速|
|---|---:|---:|
|BATTLE START|450|300|
|開始後の間|60|40|
|YOUR/ENEMY TURN|350|230|
|通常のスキル操作待機|420|280|
|HPダメージ5以上の操作待機|700|420|
|結果バナー開始まで|180|100|
|結果バナー|500|350|
|結果画面まで|850|600|

通常は旧高速を基準に、短いスキルだけさらに待機短縮。光/粒子は最大900msで別途破棄し、消滅まで操作を待たない。論理処理は従来通り逐次実行。演出世代/タスクスコープと終了・再戦・リセット時の破棄を使用する。

## エフェクト/音声

- 共通タグと実ダメージ/バリア消費/回復/状態差分から系統を選ぶ。スキル名の文字列には依存しない。
- 物理斬撃、呪い/弱体、毒、結界展開/衝撃/破壊、回復、強化、マナ集積、決着。実HPダメージ1–2/3–4/5以上を段階化。
- 命中の後100msで追加状態の視覚演出。HP/状態の論理更新順は変えない。
- 微振動とヒットストップはキャラクター/演出レイヤーに限定。中/大ダメージの画面揺れは背景位置だけを微小に動かす。HUDやレイアウトを揺らさず、ゲーム時計は停止しない。
- 標準24個/軽量10個までのエフェクトノード、粒子6個/2個。設定をlocalStorageへ保存。動きを減らすOS設定は軽量と静かな点滅へ自動反映。
- 既存SEを維持し、12種の自作SEを追加。6声上限/同音65ms抑制。通常プレイの外部通信不要。
- ボスIDごとのOGG/MP3パス/音量補正スロット。必要な1曲のみ生成、MP3フォールバック、再戦曲選択、旧曲停止。
- **BGM追加4曲は配布元確認がアクセス制限で未完了。** scoutに既存Determined Pursuitを明示割当。他4枠はpending-source、既存曲を安全に再生。5曲導入完了として扱わない。
