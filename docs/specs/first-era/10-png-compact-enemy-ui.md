# 正式PNGとボス拡大・敵デッキ小型化（最新差分）

09の仕様を土台に、ユーザーの追加指示で以下を置換。戦闘ルール・カード性能・AIは変更しない。

- 正式原本は1024×1536の提供PNG6枚。透過済み5枚は戦闘用も原本と完全一致。魔女のみ最新RGBから背景除去。指修正前透過版を人物差し替えに使わない。
- 顔・バストアップは正式PNGから再切り出し。
- PC優先でボスの存在感を拡大。全身にこだわらず顔・上半身を優先し、下半身が手札に隠れることを許可。
- キャラ個別調整：`assets/asset-map.js` の `framing`。`scale`・`x`・`y` と `mobile-scale`・`mobile-x`・`mobile-y`。位置値はCSS長さ（例 `10px`）、倍率は数値。
- 敵カードは高さ44px（スマホ43px）の横長5枚。通常は種別アイコン・名前・残CDまたは使用済だけ。コスト・基本CD・効果・条件・詳細状態は拡大時に表示。
- PC1366×768、1280×720、スマホ390×844で6人全員と敵カードの通常/CD/使用済/拡大を確認。
- 実装・テスト・スクリーンショット報告まで。コミット・プッシュ・デプロイは未承認。
