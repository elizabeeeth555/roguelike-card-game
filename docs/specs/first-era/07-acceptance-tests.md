# 07. Codex実装後の受け入れ・バランス検証チェック

**このファイルはテスト仕様であって、現在すでに実装・合格していることを示さない。** 旧版の`npm test`/`npm run check`は変更後に再実行し、失敗した旧仕様テストは新仕様に合わせて置換する。

## A. 基本ダメージ・HP

- [ ] プレイヤーHP20、ボスHP20で開始。両者最大HP20を超えない。
- [ ] 斬撃コスト1で2ダメージ、重斬コスト2で4、大振りコスト3で6。旧攻撃力ステータスに依存しない。
- [ ] バリア3の相手に2ダメージ→HP変化0、バリア1残る。
- [ ] バリア3の相手に5ダメージ→バリア0、HP−2。
- [ ] 結界／堅守の使用後、**次の相手ターン終了時に残量が消える**。次の自ターンまで残らない。
- [ ] 手当はHP最大20を超えず2回復。満タンで使う場合の表示と処理が一致する。
- [ ] 途中でHP0になれば直ちに決着し、残りスキルが自動発動しない。

## B. マナ、先後手補正、加速

- [ ] プレイヤー先攻R1は**2/3**、ボス後攻R1は**3/3**。R2以降は各自の上限まで回復。
- [ ] プレイヤーR1で加速2消費→0/3のまま。R2開始4/4。
- [ ] R2で再加速2消費→そのターンは2/4。R3開始5/5。以後加速ボタン無効。
- [ ] 残りマナを次の自ターンに持ち越さない。ラウンドごとの自動上限成長がない。
- [ ] 封脈−1を1つ受けると次自ターンの開始可能マナが上限3なら2/3になる（上限は3）。
- [ ] 封脈を複数受けても次自ターンの開始可能マナは**最低2**。妨害を消費したその次の自ターンは通常補充。
- [ ] ボスもマナ加速可能、同ターン加速2回や上限6は不可能。

## C. CD・条件・コンボ

- [ ] CD0のスキルは次の自ターンに再使用可、同じターンに2回不可。
- [ ] CD1は使用の次の自ターン使用不可、さらにその次の自ターンで使用可。
- [ ] CD2は次の2自ターン不可、3自ターン目に使用可。敵も同じ。
- [ ] 疾走斬がそのターン最初の攻撃なら3、他の攻撃の後なら1。
- [ ] 追撃は事前に**別の攻撃スキル**を使った場合3、それ以外1。
- [ ] 切り込みは対象HP11/20で2、10/20で4（使用前HP判定）。
- [ ] 戦意を先に使い、同ターンの次の攻撃+3。攻撃せず終了すると失効。
- [ ] 布石の使用**次の自ターン**の初回攻撃+2。次の自ターンで攻撃しなければ失効。
- [ ] 戦意／布石／攻撃弱体を合算してからバリア軽減。ダメージ0未満にならない。
- [ ] 毒刃・蝕心は相手の毒0なら選択不可、マナ・CDを消費しない。

## D. 毒・妨害

- [ ] 毒カウンターは最大4、追加付与も4を超えない。
- [ ] 毒3で付与追加がなければ、**毒持ち本人の自ターン終了**で3、次回2、次々回1ダメージ（合計6）。
- [ ] 毒tickはバリアを無視。毒刃／蝕心の即時攻撃はバリアで防げる。
- [ ] 毒2→腐蝕(+2)で毒4、対象が毒4で疫病(+3)しても毒4。
- [ ] 毒2の敵に毒刃→2+4=6の通常ダメージ、その後毒1。
- [ ] 毒2の敵に蝕心→2の通常ダメージ、その後毒1。
- [ ] 腐蝕を使用した同ターンに毒刃を使える（必要マナがある場合）。
- [ ] 牽制−2と毒状態時の呪詛−2は重複し次攻撃−4。次攻撃でまとめて消費。
- [ ] 攻撃スキルを使わずターンを終えた時の攻撃弱体残存処理は、02記載の確認済み仕様と一致。

## E. 道中・スキルセット・結果

- [ ] 初期2枚→獲得イベント5回（スキップ可）→2〜5枚でボス戦。強化／特殊強化／切り札の道中イベントなし。
- [ ] 3択中に同名IDなし、現在所持スキルを候補に出さない。
- [ ] 出現可能スキルはA〜Dの19種類のみ。E〜Hや旧スキルが混ざらない。
- [ ] 同一スキルIDを直接追加しようとした場合も重複防止の検証に通る。
- [ ] ボスは**5プリセットのいずれかが丸ごと選択**され、スキル個別抽選・重複・条件不成立スキルだけの事故がない。
- [ ] スキル閲覧画面でボスの5枚は見えるが、次の行動順はプレイ前に確定表示しない。
- [ ] 勝敗後は結果→再挑戦のみ。継承選択、第二紀・第三紀、強化の導線がない。

## F. ボスAI

- [ ] 5プリセットすべてで少なくとも数戦プレイでき、CD・マナ・発動条件違反なし。
- [ ] 実際の使用順が**疾走斬→追撃／戦意→攻撃／毒付与→毒刃**などの条件を正しく扱う。
- [ ] 相手をそのターンに倒せる手順があれば合理的に選び、見逃さない。
- [ ] 加速すべき状態とすべきでない状態の両方をテスト。毎ターン必ず加速しない。
- [ ] 固定盤面・固定プリセットではボスの行動が**再現可能**。行動ランダム化はない。
- [ ] 既に勝敗が確定しているときや演出中に、計画済みの行動が二重実行されない。
