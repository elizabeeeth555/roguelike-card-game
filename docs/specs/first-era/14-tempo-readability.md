# 宣言・敵行動テンポと可読性（2026-11-08）

本書は12/13の宣言時間・敵待機・文字サイズを更新する。ルール/AI/素材/音源は変更しない。
時間定義は `src/app/presentation-timing.js` に集約する。

|項目|通常|高速|
|---|---:|---:|
|全宣言（BATTLE START / YOUR / ENEMY / VICTORY / DEFEAT）|2000ms|1000ms|
|フェードイン / 維持 / フェードアウト|300 / 1300 / 400ms|150 / 650 / 200ms|
|開始宣言→YOUR TURNの間|180ms|100ms|
|ENEMY TURN終了→初動|700ms|350ms|
|敵行動開始→次の行動|900ms|550ms|
|決着→勝敗宣言|700ms|350ms|
|宣言終了→結果画面フェードイン|400ms|240ms|

待機はエフェクト時間を含めた予算。敵行動に通常900msと従来のスキル待機を二重加算しない。
プレイヤーの操作待機420/700ms（高速280/420ms）、スキル選択と詳細、習得・交換は変更しない。
ターン宣言は従来の明示的なクリック/Enter/Spaceスキップを維持する。自動短縮はしない。
宣言のPromiseが終了するまで敵の通常行動を開始せず、勝敗宣言が消えてから結果を開く。
リセットは既存のタスク世代と宣言Promise解除で中断する。OSの動き軽減では結果の移動を省き、フェードは維持する。

PCは説明・ログ15〜16px、スキル名16〜19px、主要数値15〜17px、ボタン15〜18px、補足13pxへ拡大。
敵パネル高さ122px・幅を調整し、名前/MP/概要/CDの余白を確保。手札とHUD上端も揃える。
スマホは5枚を維持し、MP・名前・効果を縦に分離する。名前12px・概要11〜12pxを下限とし、全文は15pxの詳細で読む。
スマホの操作列は高さを拡げ、マナ加速の説明のはみ出しを防ぐ。モーダルは画面内の高さに制限し、長文をスクロールできる。

強化/特性/継承は未実装のままで、旧版画面を復活させない。
