# 色マナ戦闘 PoC — 合意事項・検討事項

記録日：2026-11-16  
管理対象：『継世の王座』の**次期戦闘システムを検証する独立研究案**。ブランチ `research/color-mana-combat-poc` にのみ保存。

> **重要：現行第一紀の正式仕様・実装を置き換えない。** この文書の「合意」は、今回の設計相談で採用した**PoCの方向性**を指す。効果・コスト等の正式な採用、本編への移行、第二紀への適用は別途判断する。研究環境の実装状態は**未実装**。既存の第一紀・classic・王座工房・独立研究・セーブを変更しない。

## 1. 背景と狙い（方向性合意）

従来の「固定手札＋毎ターン固定量のMP補充＋CD」では、強い行動列が決まると同じ順序の反復になりやすく、敵の動きへの対応が薄くなる。今後は次を検証する。

- 戦闘前の**スキル自由構築**を活かしながら、毎ターンの行動選択を変動させる。
- **自分の資源抽選**と**敵の行動**が双方変化し、状況に応じて攻撃・防御・妨害・準備を選び直す。
- ランダムな引きが不利でも、基本行動と先読みで立て直す余地を持たせる。事故防止が万能になり、毎回最適解を保証する状態は避ける。
- ビルドやボスの種類を最初から増やしすぎず、**複雑さを抑えた最小PoC**で戦術性を検証する。
- 参考とする体験は『メギド72』の毎ターン変わる戦況への対応。ただしフォトン共有・取り合い等の固有ルールや表現を再現せず、**独自の色マナ方式**として設計する。

## 2. マナのルール

### 2.1 色とスキルコスト（方向性合意）

| 色 | 呼称（仮） | 主な用途 |
| --- | --- | --- |
| 赤 | 攻撃マナ | 直接攻撃 |
| 紫 | 状態異常マナ | 毒・妨害等 |
| 青 | 特殊マナ | 防御・回復・補助等 |

- すべての通常スキルは、色の指定を持つコストを設定できる。
- 基本は**必要な固定色＋任意色**。例：赤1＋任意1。
- 強力な将来スキルでは**赤2＋任意1**、**赤3**のような複数の固定色要求も可能とする。ただし最初のPoCには高コスト新スキルを追加しない。
- 「任意」は赤・紫・青のいずれでも支払い可能。プールマナの支払い可否は 2.3 に従う。
- 色による役割分けは目安であり、複合効果を持つスキルの固定色は個別に判断する。

### 2.2 排出・リロール（方向性合意＋試作値）

- **各自ターンに新規マナ3個を完全ランダムで排出**する。3個という個数は**初回PoCの仮値**。
- 初回PoCでは**リロールなし**。必要になれば後で比較する。
- 最初の研究条件として、赤・紫・青をそれぞれ1/3で**独立・等確率抽選**する案を置く。出現率の厳密な方式や偏り緩和はまだ正式決定していない。
- 新規排出した通常マナと持ち越したプールマナは別個に保持する。使用可能総数は、プールがあれば最大4個（通常3＋プール1）。

### 2.3 マナプール（合意済み）

- 自ターン終了時、**未使用の通常マナから任意の1個**を選んで保存できる（保存しない選択も可）。
- 保存上限は1個。保存した色は変わらない。
- **次の自ターンに限って使用できる**。使わずその自ターンを終えた時点で失効。再プール・保存期限延長は禁止。
- プールマナは通常マナとは**個別管理**。次の自ターンで新たにプールを選ぶ場合、当該ターンに排出された未使用の通常マナから選ぶ。
- プールマナは、**通常スキルまたは固定スキル（基本行動）の発動コスト**にのみ使用可能。固定色・任意色の**どちらにも充当可能**。通常マナと組み合わせて支払える。
- **マナ変換のコストとして消費不可、変換対象にも指定不可**。プールから通常マナへ移し替えることも想定しない。
- 「固定スキルとしてのマナ変換」自体は例外とし、上記によりプールマナを一切利用できない。

## 3. 最小PoCの構築と基本行動

### 3.1 通常スキル（採用5種は合意済み）

現行第一紀の承認済み10種から、次の**固定5種**を初回PoCに採用する。PoCで最初から自由編成・追加スキルを開放しない。**効果・CD・同ターン使用制約は、原則として既存の[スキル正本](../features/skills.md#first-era-candidates)を参照**し、ここで独立再定義しない。

| 通常スキル | PoC用の色マナコスト | 位置づけ |
| --- | --- | --- |
| 斬撃 | 赤1 | 基本攻撃 |
| 重斬 | 赤1＋任意1 | 高効率攻撃 |
| 結界 | 青1 | 防御 |
| 腐蝕 | 紫1 | 毒による継続ダメージ |
| 牽制 | 紫1 | 次の攻撃への妨害 |

この**色コストは研究案の採用候補**であって、現行第一紀の既存MP値を修正する承認ではない。スキル個別の仕様が正式化する際は `docs/features/skills.md` に一元化する。

### 3.2 基本行動セット（固定型を初回試作）

- 通常5枠とは別に、どの色構成でも使える**共通の基本行動セット1種類**を置く。
- 将来は「基本行動＋奥義」の**固定型セットを選択**できるアイデアがあるが、**初回PoCは奥義なし、セット選択なし**。
- 固定セット候補（数値は調整可能な**初回試作値**）：

| 基本行動 | コスト | 効果 | 仮の制限 |
| --- | --- | --- | --- |
| 基本攻撃 | 任意1 | 1ダメージ | 自ターン1回 |
| マナ変換 | 通常マナ1個を消費 | **別の未使用通常マナ1個**を好きな色に変更（変換後の合計通常マナ数は1減る） | 自ターン1回 |

**基本攻撃とマナ変換が常に最適にならないこと**を重点検証する。特に変換には少なくとも通常マナ2個が必要で、プールマナを消費・変換して代用することはできない。

現行の固定奥義《戦技の残響》は、**現行本編の承認済み・実装済み仕様として維持**する。研究PoCから除外することは本編廃止を意味しない。将来のセット選択・奥義への派生は別判断。

## 4. 敵と予告（方向性合意、細部未確定）

- 敵も毎回同じ行動を繰り返すのではなく、**戦況とランダム性により行動が変わる**。
- **部分予告方式を採用**：実際の技名や正確なダメージを全部公開するのではなく、攻勢・強攻撃の可能性・守勢等、**行動の傾向**を示す。予告と実行行動の種類は矛盾させない。
- 直近の敵行動については比較的具体的に、**次回の敵行動については大まかな予兆**を示す方向。次回予兆を見ながら青等をプールできるようにする。ただし**表示する予告情報は最小限**にし、UIを複雑化しない。
- 敵の行動をこちらの選択を見て理不尽に後出し変更しない方向。行動候補の決定・公開タイミングと、プレイヤー行動が敵に与える影響は実装前に明確化する。
- **ボスは英雄と同じ色マナ抽選方式に縛られない**。独自の行動ルールを採用可能。
- 初回PoCは研究用ボス**1体**を想定。通常攻撃／強攻撃／防御など少数の行動候補から始める。具体的な威力、予兆分類、抽選率、AI仕様は**未決定**。過去に出た「3ダメージ／7ダメージ／バリア4」は試作例であり確定数値ではない。
- 正式な第一紀の老王《断誓一閃》の周期・威力等の既存仕様には触れない。将来の継承王が前代英雄の通常5スキルを継承する方針も維持し、**王の行動資源ルールは別設計可能**とする（[ボス正本](../features/bosses.md)、[進行正本](../features/progression.md)、[AI正本](../features/ai.md)参照）。

## 5. 研究範囲・評価

**初回PoCの最小範囲**
1. 通常5スキル固定、3色マナを3個ランダム排出、リロールなし。
2. 基本行動2種（1固定セット）、奥義なし。
3. 1ターン限りの1個プール、個別管理・変換不可・通常/固定スキルの支払いのみ可。
4. 行動が変化する研究用ボス1体、直近／次回の部分予告を簡潔に提示。

**評価すべきこと**
- 同じ使用順の反復が最善になっていないか。戦闘ログの行動列・連続同型ターン割合。
- 敵の予告が攻守・プールする色・マナ変換の判断を実際に変えるか。
- 不利な抽選で「使える技がない」「ほぼ負けが確定する」頻度が高すぎないか。
- 基本攻撃・マナ変換に偏り、色コストやスキル構築の意味が消えないか。
- 毎ターンの操作数・確認事項が多すぎず、戦闘テンポが悪化しないか。
- ビルド追加は**1ビルド→役割別少数ビルド→制限付き自由構築**の順に検討し、ボス調整負荷と継承AIの負荷を確認する。**単純な勝率最大化だけを評価目標にしない。**

**初回PoCで自動採用・実装しないこと**
- 既存の第一紀10スキル・固定奥義・老王・第二紀継承仕様の変更、本編の保存形式変更。
- スキルプール拡張、複数ボス追加、全種類の戦技セット、リロール、過度な予告・複合ギミック。
- 既存のマナ加速処理の新ルールへの無条件移植。加速と色マナの相互作用は別途検討する。

## 6. 未決定・実装前の確認事項

- ターン内の**行動解決順**、敵の直近／次回予告と行動確定のタイミング、AIの確率・条件。
- 通常マナとプールマナの両方で払える場合の**支払い優先／手動指定**、プール消費のUI。
- 基本行動と各スキルの調整値、HP・ボス火力・CD等の既存値を試作にどこまで流用するか。
- 長期的にはリロールやマナ排出補正が必要か（**初回はなし**）。
- 色の名称・配色・表示位置、予兆UI、ボス行動の情報公開量。
- セット選択を将来導入する場合の固定行動／奥義の組み合わせ、英雄・継承王への反映範囲。
