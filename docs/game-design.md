# 継世の戦闘 — ゲーム設計

更新：2026-11-06。現行は**第一紀・新戦闘ルール検証版**。
次バージョン番号は未確定で、package.jsonの0.9.5は採番前の管理値として保持している。
資料一覧は [README.md](README.md)、実装前の確認結果は [first-era-decisions.md](first-era-decisions.md)。

## コンセプト【方向性合意】

シングルプレイヤーPvE。短い道中でビルドを作り、スキルの組合せ・準備・使用順から大きな効果を生む。
将来は前代の通常スキルセットを次代ボスにし、今の強さが未来の敵を強くするジレンマを目指す。
ただし現在は第一紀の戦闘バランスを先に検証し、三世代進行や継承を現行入口に戻さない。

## 現行仕様【実装済み・数値は検証値】

| 項目 | 現在の挙動 |
|---|---|
| 進行 | 初期2枚→獲得イベント5回（入れ替え/スキップ・リロール合計2回）→通常2〜5枚→ボス1戦→結果 |
| スキル | A共通6・B速攻4・C中速4・D毒5の19種。固定手札、同ID重複なし |
| 初期ビルド | 速攻：斬撃＋疾走斬／中速：重斬＋牽制／毒：腐蝕＋斬撃 |
| HP | 双方20。攻撃力ステータスなし |
| マナ | 初期上限3、プレイヤー先攻初回2/3、後攻ボス3/3。持ち越さず補充 |
| 加速 | 2消費・各自ターン1回。次自ターン開始時に上限＋1（最大5）→補充→妨害減算（最低2） |
| 使用制限 | 各スキルは自ターン1回。CD1は次の自ターン不可、CD2は次の2自ターン不可 |
| 毒 | 0〜4カウンター。本人の終了時に現在値のHP直接ダメージ、次に1減る |
| バリア | 同ターン中は合算。次の相手ターン終了で残量消去 |
| 弱体 | 次の攻撃スキルまで持ち越し、同種も合算、0ダメージでも消費 |
| 攻撃タグ | 即時ダメージを持つスキルすべて。毒付与・終了時毒tickは含めない |
| 一時強化 | 戦意＋布石は合計＋5。条件込み基本値＋バフ−弱体（最低0）→バリア |
| ボス | 固定5枚の5プリセットから1組を戦闘開始時に抽選。行動順は決定的な合法手探索 |
| 再戦 | 勝敗とも同条件再戦と最初から。同条件では自分の2〜5枚・敵構成を維持し、戦闘状態を全初期化 |

詳細：[戦闘ルール](specs/first-era/02-combat-rules.md) ／ [19スキル](specs/first-era/03-card-pool-A-D.md) ／ [進行・ボス](specs/first-era/04-progress-and-boss-presets.md)。
スキル値・コスト・HPは試作用であり、実装済みという理由で正式バランスへ昇格させない。

## 画面・素材【実装済み】

PCは中央の大きなボスと上部の敵HUD・公開5枚、左下の顔付きプレイヤーHUD、下部の通常5枚＋継承予約枠。手札右側に加速・終了操作を縦配置。スマホは縦配置。敵味方各1枚のインライン拡大と、選択後の使用確認を使う。
攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合タグも文字で明記する。
継承専用枠・ボス固有・プレイヤーパッシブは予約表示だけで、効果を持たない。
新しいユーザー提供6キャラの立ち絵・顔を使用し、大男・斥候も表示。5ボスのスキルセットは維持。
最新の[古城UI指示](specs/first-era/09-castle-ui-request.md)に従い、回廊／玉座背景、敵味方通算1枚拡大、右端中央ログタブを使用。
BGM/SE、スキップ・高速演出、開閉ログは継続。

詳細：[UI仕様](specs/first-era/05-battle-ui-spec.md) ／ [素材仕様](specs/first-era/06-assets-and-characters.md)。

## 開発方針と残課題

classic scriptによるfile://起動とGitHub Pages互換を維持し、ルールとDOM・音声・演出を分離。
React・TypeScript・サーバー・DBは今回導入しない。[構成資料](first-era-architecture.md)を参照。
PC・スマホの実機プレイ、音声の聴感、防御型AIの長期化、相性差、仮素材品質は継続確認する。
新しい仕様は承認済み／実装済み／検証値／未承認／未実装を分けて記録し、無断で数値を変えない。

2026-11-06 PC戦闘UI改修：最新UI方針は[PC UI仕様](specs/first-era/08-pc-battle-ui.md)。戦闘ルール・スキル値・AIは変更していない。

## 最新反映（2026-11-07）

正式採用・本体反映：結界/堅守CD1、AI-2（上位8＋加速/布石各最大2候補）、12Rから各自ターン開始の消耗ダメージ。毒は終了時を維持。
デモ暫定：獲得イベント5回、上限5枚で入れ替え、周回合計2リロール、無制限スキップ。全スキップなら初期2枚で戦闘可能。新周回は回数初期化。
AI-L/AI-D/AI-4、幅24、探索延長、強化/特性/継承6枚目は未実装。詳細は `docs/specs/first-era/11-ai-exhaustion-draft.md`（リポジトリルート基準）。過去研究は当時の条件として保持する。

## スキル構築型RPGのUI（2026-11-07）

現行の方向性はスキル構築型ローグライクRPG。最新UI仕様は `docs/specs/first-era/12-skill-ui.md`（ルート基準）。スキルのMP/基本CDを独立表示、使用済/CD中は排他、詳細は効果全文のみ。習得詳細のリロール/スキップは通常画面へ集約。BATTLE STARTとターン演出、毒・数値演出、HUDを改善。内部card/deckは互換性のため維持する。戦闘・習得ルールは前回の採用仕様から変更しない。

戦闘テンポ/交換画面/FX・音声の現行表示仕様は[13-combat-presentation](specs/first-era/13-combat-presentation.md)を参照。追加BGM4曲は素材確認待ちで未収録。
