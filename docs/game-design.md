# 継世の戦闘 — ゲーム設計

更新：2026-11-06。現行は**第一紀・新戦闘ルール検証版**。
次バージョン番号は未確定で、package.jsonの0.9.5は採番前の管理値として保持している。
資料一覧は [README.md](README.md)、実装前の確認結果は [first-era-decisions.md](first-era-decisions.md)。

## コンセプト【方向性合意】

シングルプレイヤーPvE。短い道中でビルドを作り、カードの組合せ・準備・使用順から大きな効果を生む。
将来は前代の通常デッキを次代ボスにし、今の強さが未来の敵を強くするジレンマを目指す。
ただし現在は第一紀の戦闘バランスを先に検証し、三世代進行や継承を現行入口に戻さない。

## 現行仕様【実装済み・数値は検証値】

| 項目 | 現在の挙動 |
|---|---|
| 進行 | 初期2枚→未所持3択から獲得を3回→通常5枚→ボス1戦→結果 |
| カード | A共通6・B速攻4・C中速4・D毒5の19種。固定手札、同ID重複なし |
| 初期ビルド | 速攻：斬撃＋疾走斬／中速：重斬＋牽制／毒：腐蝕＋斬撃 |
| HP | 双方20。攻撃力ステータスなし |
| マナ | 初期上限3、プレイヤー先攻初回2/3、後攻ボス3/3。持ち越さず補充 |
| 加速 | 2消費・各自ターン1回。次自ターン開始時に上限＋1（最大5）→補充→妨害減算（最低2） |
| 使用制限 | 各カードは自ターン1回。CD1は次の自ターン不可、CD2は次の2自ターン不可 |
| 毒 | 0〜4カウンター。本人の終了時に現在値のHP直接ダメージ、次に1減る |
| バリア | 同ターン中は合算。次の相手ターン終了で残量消去 |
| 弱体 | 次の攻撃カードまで持ち越し、同種も合算、0ダメージでも消費 |
| 攻撃タグ | 即時ダメージを持つカードすべて。毒付与・終了時毒tickは含めない |
| 一時強化 | 戦意＋布石は合計＋5。条件込み基本値＋バフ−弱体（最低0）→バリア |
| ボス | 固定5枚の5プリセットから1組を戦闘開始時に抽選。行動順は決定的な合法手探索 |
| 再戦 | 勝敗とも同条件再戦と最初から。同条件では自分の5枚・敵構成を維持し、戦闘状態を全初期化 |

詳細：[戦闘ルール](specs/first-era/02-combat-rules.md) ／ [19カード](specs/first-era/03-card-pool-A-D.md) ／ [進行・ボス](specs/first-era/04-progress-and-boss-presets.md)。
カード値・コスト・HPは試作用であり、実装済みという理由で正式バランスへ昇格させない。

## 画面・素材【実装済み】

PCは左下手前に英雄の背面、右上奥にボス正面。スマホは縦配置、カード詳細から使用確認。
攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合タグも文字で明記する。
継承専用枠・ボス固有・プレイヤーパッシブは予約表示だけで、効果を持たない。
大男・斥候の画像は使わず代替表示、他4キャラの12PNGを使用。5ボスのデッキは維持。
BGM/SE、スキップ・高速演出、開閉ログは継続。

詳細：[UI仕様](specs/first-era/05-battle-ui-spec.md) ／ [素材仕様](specs/first-era/06-assets-and-characters.md)。

## 開発方針と残課題

classic scriptによるfile://起動とGitHub Pages互換を維持し、ルールとDOM・音声・演出を分離。
React・TypeScript・サーバー・DBは今回導入しない。[構成資料](first-era-architecture.md)を参照。
PC・スマホの実機プレイ、音声の聴感、防御型AIの長期化、相性差、仮素材品質は継続確認する。
新しい仕様は承認済み／実装済み／検証値／未承認／未実装を分けて記録し、無断で数値を変えない。
