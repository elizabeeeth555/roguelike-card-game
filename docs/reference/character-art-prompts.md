# ローグライクカードゲーム：キャラクター立ち絵発注プロンプト（6人×3素材）

- ステータス：**仮素材制作向けの発注ドラフト**（キャラクター設定・名称は未確定）。
- 用途：同一人物が「プレイヤー時は後ろ姿」「後の世代のボス時は正面立ち絵」として登場するゲーム。全キャラに3点（ボス用全身・顔アイコン・プレイヤー用後ろ姿）が必須。
- 納品仕様：各キャラ **別ファイルの透過PNG 3点**。全身・後ろ姿は縦長2:3目安（推奨1536×2304px以上）、顔アイコンは1:1（推奨1024×1024px以上）。縦横比・画素数は生成サービスの対応範囲で最大限近づける。
- **生成運用**：まず「ボス用全身」1枚を確定。次にその画像を画像参照として添付し、「顔アイコン」「後ろ姿」を**別々に**生成。3枚同時に出せないツールで三面図や1枚のコラージュを納品しない。
- 共通スタイル：高品質なオリジナル・ハイファンタジーJRPG用2Dキャラクターイラスト。洗練されたアニメ塗りと少し厚みのある陰影、明瞭な輪郭、華やかな配色。ただし戦闘画面で縮小しても判別できるシルエットを優先。写実写真・3Dレンダリング・チビキャラは避ける。
- 共通禁止：背景・地面・落ち影・文字・ロゴ・ウォーターマーク・枠・吹き出し・過剰な粒子・余分な手足・武器の欠損・頭足の見切れ。PNGのアルファチャンネルで真の透明背景。顔アイコンは肩上までが収まる。全身と後ろ姿は頭頂〜足先と武器全体が収まる。
- 向き：ボス用全身は画面右上奥に配置する想定で、正面寄り3/4視点・**左斜め下へ視線**。後ろ姿は画面左下手前に配置する想定で、背中寄り3/4視点・**右斜め上に顔と体を向ける**。左右非対称の装飾や武器の持ち手は視点が変わっても同一人物として矛盾しないようにする。

## 01 黒剣士 — 「夜刃の剣士」

```text
オリジナルのファンタジーRPG用キャラクター素材を発注する。以下に指定した**同じ一人**について、ボス用全身・顔アイコン・プレイヤー用後ろ姿の3種類を、別々の透過PNGファイルとして制作する。まずボス用全身を1枚完成させ、後の2素材では必ずその完成画像を参照して、顔、衣装、武器、色、左右の装飾を一致させる。

キャラクター：夜刃の剣士。20代後半の男性。細身で長身、俊敏な剣術家。少し長い黒髪を低い位置でひとつ結びにし、前髪は右目のそばに垂れる。鋭い灰銀色の瞳、無口で冷静な表情。漆黒の軽装コート、暗い革の胸当て、左肩だけに銀の肩甲、深紅の細い腰布。右手に細身の片手長剣、剣の鍔に赤い石。色は黒・銀・深紅。鎧の塊ではなく、軽さと鋭いシルエットを重視。体格は細身で筋肉質。

①ボス用全身：全身が入る縦長2:3構図。正面寄りの3/4視点、左斜め下の対戦相手を鋭く見据え、右手の剣を低く構える。威圧感のある自然な戦闘待機ポーズ。頭頂、足先、剣先まで見切れなし。
②顔アイコン：正方形1:1。顔〜肩のアップ。結んだ黒髪、灰銀の瞳、左肩の銀甲冑、赤い腰布と調和した首元の赤い差し色で識別できる。静かな不敵の表情。小さくしても見分けられる明瞭な顔立ち。
③プレイヤー用後ろ姿：全身が入る縦長2:3。左下手前から右斜め上の敵を見ている、背中主体の3/4バックビュー。低い位置の結び髪、左肩の銀甲冑、深紅の腰布、右手の長剣が①と完全に一致。振り返って顔を大きく見せない。

画風：統一された高品質な2DハイファンタジーJRPGのアニメイラスト。輪郭明瞭、品のあるセル塗り＋柔らかな陰影、ゲームUIに映える少し派手な装飾。背景・地面・影・文字・枠・ロゴ・ウォーターマークなし。各画像は真の透過PNG、十分な余白、顔・頭・足・武器を切らない。画像間で服装を変更したり、武器を逆の手に持たせたりしない。3種類を1枚にまとめず独立した3素材として納品。
```

## 02 重装騎士 — 「蒼鋼の守護騎士」

```text
オリジナルのファンタジーRPG用キャラクター素材を発注する。以下の**同一人物**について、ボス用全身・顔アイコン・プレイヤー用後ろ姿を別々の透過PNGで制作する。最初にボス用全身を確定し、その画像を後の2点に参照させ、鎧の各パーツ、左右配置、顔、武器を統一する。

キャラクター：蒼鋼の守護騎士。40代の女性。背が高く肩幅が広い、筋肉質な熟練騎士。赤褐色の髪を後頭部で太い三つ編みにし、深緑の目、凛とした顔立ち。銀青色の重厚なプレートアーマー、金色の縁取り、胸に青い菱形の紋章。右手に長槍、左腕に大きな長方形の青い盾。頭は開放型の冠状ヘルムで顔が見える。濃紺の短いマント。色は鋼青・金・濃紺。黒剣士とは対照的に重さ、守護、安定感を感じるシルエット。

①ボス用全身：縦長2:3、全身。正面寄り3/4、画面左斜め下に視線。盾を手前、槍を右側に構える防御的な待機姿勢。大きな肩甲・盾・槍が全て収まる。鎧の金属感は強いが顔が読めること。
②顔アイコン：正方形1:1、胸上まで。赤褐色の三つ編みの根元、深緑の瞳、開放ヘルムと金縁、年齢を感じさせる自信ある表情。厳格だが頼れる存在感。
③プレイヤー用後ろ姿：縦長2:3、全身の背中寄り3/4ビュー。左下手前から右斜め上を向く。三つ編み・濃紺マント・銀青の鎧・左腕の盾・右手の槍が①と矛盾しない。盾の裏側、鎧の背面構造も描く。

画風：高品質なオリジナル2DハイファンタジーJRPGアニメイラスト。6キャラで線の太さと陰影表現を統一し、細密すぎずUI縮小時に識別可能。背景・地面・落ち影・文字・ロゴ・ウォーターマーク・飾り枠なし。真の透明背景PNG。全身は頭頂から足先、槍先まで見切らない。顔アイコンは切り抜きしやすい余白付き。3素材は別ファイルで納品し、衣装・色・武器を変更しない。
```

## 03 魔女 — 「紫苑の魔女」

```text
オリジナルのファンタジーRPG用キャラクター素材を発注する。同じ一人を、ボス用全身・顔アイコン・プレイヤー用後ろ姿の3点に描き分け、それぞれ独立した透過PNGで納品する。まず全身絵を固め、顔アイコンと後ろ姿はその画像を必ず参照して一致させる。

キャラクター：紫苑の魔女。30代前半の女性。細身で背は平均的、優雅だが底知れない雰囲気。肩に届く銀紫のウェーブ髪、前髪の片側だけ長い三つ編み、琥珀色の瞳。ゆるく曲がった大きなつばの紫の魔女帽、帽子の左側に小さな金の三日月飾り。濃紫と黒のレイヤードドレス、淡い翡翠色の内布、細い金の刺繍、足首までの編み上げブーツ。右手にねじれた木製の杖、先端に翡翠色の鉱石。色は紫・翡翠・金。幼すぎず、知的で少し妖艶、顔つきは大人の魔術師。

①ボス用全身：縦長2:3、全身。画面右上奥に置く想定。正面寄り3/4で左斜め下を向く。杖を右手に持ち、左手の指先で小さな魔法の光を操るポーズ。魔法エフェクトはシルエットを邪魔しない控えめなもの。帽子の先、杖、ブーツまで画面内。
②顔アイコン：正方形1:1、顔と肩を大きく。銀紫の左右非対称な三つ編み、琥珀色の目、金の三日月飾り付き帽子、口元の意味深な微笑み。帽子の識別要素を残しつつ顔を小さくしすぎない。
③プレイヤー用後ろ姿：縦長2:3、全身。背中主体の3/4ビューで右斜め上を見る。大きな帽子の後部、銀紫の髪、翡翠色の内布が見える裾、右手の杖を①と厳密に一致。左手にごく小さな淡い光。

画風：統一されたオリジナル2DハイファンタジーJRPG、アニメ寄りで華やかながら明確な輪郭。背景・地面・落ち影・文字・ロゴ・ウォーターマーク・フレームなし。真のアルファ透過PNG、3素材は別画像、全身は見切れなし、顔アイコンは小サイズでも判別可能。3枚で服装のパーツや帽子の装飾の位置が入れ替わらない。
```

キャラクター：鉄拳の巨漢。40代半ばの男性。身長2m級、圧倒的に分厚い胸板と腕、太い脚を持つ巨漢。褐色の肌、頭を短く刈り込んだ黒髪、顎に四角い黒髭、左眉に古い一本傷、茶色の瞳。豪快だが残虐ではない表情。使い込まれた焦茶色の革鎧、毛皮の肩掛けは右肩だけ、太い鉄の腕輪、オレンジ色の腰帯。巨大な鉄頭の戦槌を両手で扱う。色は焦茶・鈍鉄・橙。黒剣士や騎士とは明確に違う、幅広く重量感のあるシルエット。人間らしい自然な解剖学的体型で、誇張しすぎた怪物にはしない。

画風：高品質なオリジナル2DハイファンタジーJRPGアニメイラスト。明瞭な輪郭、メリハリある陰影、ゲームUIで見やすい配色。背景・地面・影・文字・ロゴ・枠・ウォーターマークなし、真の透過PNG。余白を確保して人物と武器は欠けない。3種類は個別ファイル、鏡像反転による非対称装飾の矛盾を避ける。

## 画像生成ツールへの実務指示

1. まず各キャラの「ボス用全身」を生成し、デザインを確定する。これを各キャラ固有の参照画像として保存。
2. 同じ全身画像を参照として添付し、「②顔アイコンのみ」を生成する。**3点セット中の②だけ**と明示してほかの素材を同時生成しない。
3. 同じ全身画像を参照として添付し、「③プレイヤー用後ろ姿のみ」を生成する。特に武器を持つ手、左右非対称な装飾を保つ。
4. 透明背景が本当にアルファ透過になっているか確認する（白背景を透明と誤認しない）。必要なら画像編集で背景除去する。
5. ファイル名案：`character_01_boss.png` / `character_01_face.png` / `character_01_back.png`（01〜06）。画像をまとめてリポジトリに入れる際は、各素材の利用条件を確認する。
6. Codex実装側は、キャラクター定義とアセットパスを分離し、素材差し替えでUIロジックに変更を要しない設計にする。
