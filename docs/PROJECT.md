## 4. GitHub操作権限

| 操作 | 許可の境界 |
|---|---|
| 読取・調査・レビュー | 利用可能な範囲で可 |
| 本導入の作業ブランチ作成・運用ファイル変更・commit/push | 今回の導入依頼の範囲内で可。ゲーム本体の変更は含まない |
| 新しいIssue作成・固定Inbox初期化、継続的なメモ書込 | 対象／担当／書込先を示した別途承認が必要 |
