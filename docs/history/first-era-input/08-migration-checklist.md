## 実装とコード品質の順序

1. 現行Gitブランチ・未コミット差分確認。大幅なファイル置換やデータ消去はしない。
2. ゲームの**状態遷移と純粋なカード処理**を先に更新。戦闘とAIは同じ合法手判定を使用。
3. ルール変更ごとにテスト。カード19種の表示と実効果を一致させる。
4. 道中3選択・ボス固定プリセット・結果で1周完結を繋ぐ。
5. 最後に画像18点と新UI。既存BGM/SE/演出の回帰も確認。
6. ゲーム実体の変更と文書更新を分けて報告。**このZIPそのものにはゲームコードを含めない**。

## 旧版機能を誤実装しないための注意

- 新版でもプレイヤーが5枚の通常手札を持つことは変わらないが、**旧第1紀の8種のカードや切り札は戻さない**。
- 古い「結界＝6軽減」ではなく、新版「**バリア3、次の相手ターン終了で消滅**」。同名カードでも旧コードを参照しない。
- 古い「腐蝕＝即時2ダメージ＋持続毒」ではなく、新版「**毒2カウンター付与のみ**」。
- 「継承カード」はゲームの主要コンセプトだが、第一紀版の**予約枠はロックのみ**。強化済みカードの継承実装を始めない。
- 第2/3紀で使っていた「ボス固有能力」は、第一紀版では**アイコンのみ**。
- 攻撃力のUIは削除するが、**マナ上限は攻撃力と別物**。マナ加速は毎ターン自動で上がるものではない。
