# スキル個別仕様の正本

## 管理範囲と参照方法

実装済み・実装予定・研究中・保留・廃止を含む**全スキルの個別仕様は本書だけで管理**する。名称、実行時ID、効果、MP、CD、使用条件、タグ、個別強化、固定奥義、スキル固有のUI・素材設定が対象。他資料は該当節をリンクし、同じ定義を転記しない。

毒・バリア・CD等の共通処理は[戦闘](combat.md)、編成枠・解放・強化予算等の共通進行は[進行](progression.md)、ボス固有能力は[ボス](bosses.md)、共通パネル・操作は[UI](ui.md)が正本。スキルによる個別例外だけを本書へ記録する。状態区分は[資料入口](../README.md)、更新手順は[運用規約](../development-workflow.md#仕様の単一正本管理)を参照する。

本書の旧公開版表・研究仮定・未承認草案は、新プロトタイプの承認済み仕様と別区分。以下の未確認欄は「未決定」と「過去の承認本文を参照できず未反映」を区別する。コードは現行動作の証拠であり、新仕様承認の代わりではない。

### 返礼

**確定した核**：直前の敵ターンにバリアが実際に吸収した量を合算して記録する。次の自ターンに任意使用する攻撃。複数攻撃を合算し、付与したバリア量を参照しない。記録は対応する自ターン終了まで。使用で記録を消費し、二重利用・反撃からの反撃連鎖を起こさない。
使用条件は有効な吸収記録が1以上あること。

**検証中**：MP1/CD1、吸収量×1.0/1.5/2.0（端数切捨て）、対象選択、強化・弱体・攻撃履歴・構え補正との関係。
研究では使用時に攻撃対象を選び、既存の防御計算へ接続する。固定のバリア無視攻撃として正式決定したものではない。

### 結界転化

**確定した核**：自ターンに事前準備し、次の敵ターン終了時、バリア自然消滅より前に残存量を全消費して攻撃へ変換する。敵が攻撃しなくても発動。残量0なら0ダメージ。1回限りで準備解除。

**検証中**：MP1/CD1、残存量×1.0/1.5/2.0（端数切捨て）、準備時の対象指定と対象消滅時の扱い、攻撃強化・弱体・履歴。
現在の研究仮定は、敵の終了時毒と生存確認の後、バリア自然消滅前に発動する順序。準備は非攻撃、発動は強化・弱体・構え・敵バリアを参照するが、通常攻撃履歴へ入れない。0残存では強化・弱体を消費しない。
対象の旗は個体番号で固定し、消滅・別個体化なら残存全量を消費して不発、別対象へ振り替えない。旗Bは敵開始時に再演して消えるため、準備した転化でその再演を阻止できない。勝敗確定時は準備解除。
返礼は研究では通常攻撃履歴を使う。両者の倍率積はまず切捨て、その後に構え等を適用。通常スキル・再演・一閃の実吸収を記録し、返礼／転化・毒・消耗から新たな反撃記録を作らない。これらの分類・順序・対象消滅処理は**検証中**の仮定であり、正式仕様へ昇格しない。

両者は同じ敵ターンを独立して参照できる。バリア8のうち5吸収なら返礼の参照5、転化の参照3。片方の発動だけを理由に他方の記録を消さない。
