# UI・操作・演出

## 現行の表示と操作（本編実装済）

スキル構築型ローグライクRPGとして表示を統一する。カード→スキル、獲得→習得、デッキ→スキルセット、継承カード→継承スキル。内部のcard/deckは互換性のため残す。
PCは中央ボス、公開敵5スキル、顔HUD、手札右の操作列、開閉式ログ。プレイヤー全身立ち絵は通常表示しない。
PCのプレイヤーHUD上端は手札上端へ揃え、下へ将来拡張可能にする。顔アイコンはPC50px・スマホ44pxを基準。スマホは敵→戦闘領域→自分の情報とスキルという縦導線。
右上は音量→設定。毒アイコンは紫、プレイヤーと敵の数字は読みやすくする。

### スキルパネル・詳細

- 左上：名前、右上：♦MP、中央：効果概要、右下：基本CD（0も表示）。分類は補助情報。
- 使用した所有者の自ターン中は「使用済」。終了後CDがあれば「CD中（残nT）」。排他表示とし、異なる色で区別する。
- 使用不可暗転でも文字を読める。MP不足・条件未達は既存合法判定に従う。
- 選択→詳細確認→使用の二段階。詳細文章は効果全文のみ。プレイヤーは使用ボタン、敵は使用ボタンなし。
- ダメージ予測の内部計算は残すが、長文の使用状態・予測・CD定義を効果文章へ混ぜない。
- 本体の位置を保ち、詳細枠だけ画面端で補正する。敵味方の左右端を中央へ大移動させない。通算1つの選択を基本とする。
- ターン終了時は合法なスキル／加速が残る場合に確認する。単なる余剰MPだけでは確認しない。

### 習得・交換・結果

通常習得画面にリロールとスキップ。詳細モーダルは名前・全文・閉じる・「このスキルを選択」。MP/CDは候補側で確認する。
交換候補は名前・MP・CD・概要、全文確認と交換確定を区別。取消は候補と分離した下部操作。交換中はリロール／スキップを隠す。取消で候補・残数・イベント進行を保持する。
勝敗後の操作不能理由は「戦闘終了」を「演出中」より優先。結果から再戦／最初からへ。古い継承画面を復活させない。
ログは開閉式ドロワー。閲覧中のスクロール位置へ配慮し、右上設定と干渉させない。

## 最新の時間定義

[時間定義コード](../../src/app/presentation-timing.js)に一致する2026-11-08版。過去の約3秒、350ms等の宣言時間を置換する。これは演出設定であり戦闘ルールの時間ではない。

| 項目 | 通常ms | 高速ms |
|---|---:|---:|
| BATTLE START / YOUR / ENEMY / VICTORY / DEFEAT | 2000 | 1000 |
| フェードイン／維持／アウト | 300/1300/400 | 150/650/200 |
| 開始宣言→YOUR TURNの間 | 180 | 100 |
| ENEMY宣言終了→初動 | 700 | 350 |
| 敵行動開始→次の行動（演出を含む予算） | 900 | 550 |
| 決着→勝敗宣言 | 700 | 350 |
| 宣言後の結果フェード | 400 | 240 |
| プレイヤー通常／大ダメージ操作待機 | 420/700 | 280/420 |

BATTLE START完全終了→間→YOUR TURN。再戦も新戦闘として開始。YOUR青、ENEMY赤。常設ターン表示も高コントラスト。
宣言はクリック／Enter／Spaceで明示スキップ可能。敵行動は宣言完了後。敵行動予算と既存スキル待機を二重加算しない。

## FX・音声・可読性

タグと実結果から斬撃、毒、魔法、結界、回復、強化、マナを選ぶ。HPダメージ1〜2／3〜4／5以上で強弱を分け、バリア被弾・破壊をHP被弾と区別する。
ダメージは赤系「−数値」、回復は緑系「＋数値」、ハートなし。敵は上部、プレイヤーは下部に分ける。
追加状態の視覚演出は命中から約100ms遅らせる。論理計算順を遅延・変更しない。
論理処理と主要命中が終われば操作を戻し、残光の完全消滅を待たない。タスク世代で二重入力・リセット後の残留を防ぐ。
標準／軽量を保存。軽量は粒子と揺れを減らす。OSの動き軽減も尊重。HUDのレイアウトを揺らさない。
PC敵パネルは高さ122px基準（旧44pxを置換）。スマホ5枚の名前12px・概要11〜12px、詳細15px基準。狭幅は省略し全文を詳細へ。
BGM/SEのミュート・音量は維持。既存SEと自作12種、同音抑制・同時再生制限。5ボス別BGMの基盤はあるが追加4曲は未収録。権利・実ファイルは[素材](world-assets.md)。

## 最新の確定方針／未実装

単体立ち絵を現状より縮小する方向は確定。85〜90%は試験用の暫定範囲で、実数値の採用は未確定。複数体はさらに縮小し、統一敵表示領域を使う。
戦王単体中央→旗出現で王が右へスライド、旗は左・常に前面。旗HPと予告は遮らない。旗が消えれば王は中央へ。現研究配置との違いは[ボス](bosses.md)。

### 王座イベント（順序は確定／未実装）

1. ボス部屋に入る。
2. 暗転・フェードで王座イベント絵へ。
3. 座る王を表示。
4. ごく緩やかに拡大。
5. ボス名をフェード表示。
6. 名前が出た段階でBGM開始。
7. 余韻の後、暗転して戦闘へ。
8. BGMを中断・再開始せず継続。

拡大率・各時間は未確定。画像の採用と登録を区別する。
