# 戦闘システム

## 最新仕様と既存実装の境界（2026-11-11）

新しい第一紀プロトタイプは[自由編成](progression.md)の通常5スキル＋別枠の英雄固定奥義で老王へ挑む。**方針確定／新導線・奥義・老王統合は未実装**。具体的な10通常スキルと老王の数値は未確定。以下のHP・初手MP等は現行公開デモの基準であり、新プロトタイプのバランスを今回再確定したものではない。既存コアを可能な限り再利用し、明示変更していないルールは維持する。研究の初手MP3や構え数値を無断採用しない。

## 現行公開デモの概要・確定仕様

固定スキル制。自ターンにMPと使用条件を満たすスキルを任意順に使い、終了すると相手へ移る。HP0以下で直ちに決着し、残り行動を止める。通常攻撃力ステータス・ドロー・山札は使わない。

| 項目 | 現行条件 | 仕様状態 | 実装状態 |
|---|---|---|---|
| HP | 双方20、回復は最大HPまで | 暫定（デモ基準値） | 本編実装済 |
| 初手 | プレイヤー先攻MP2/3、ボス3/3 | 暫定（補正値） | 本編実装済 |
| 以降の補充 | 自ターン開始に上限まで、余剰持越しなし | 確定 | 本編実装済 |
| 加速 | MP2、同自ターン1回、次自ターンから上限+1、最大5 | 確定 | 本編実装済 |
| CD | 使用者の自ターン基準。CD0も同ターン1回 | 確定 | 本編実装済 |
| 結界・堅守 | CD1。他は既存値維持 | 確定 | 本編実装済 |
| 毒 | 所有者の自ターン終了時に残数ダメージ→1減少、上限4 | 確定 | 本編実装済 |
| 消耗 | 12Rから各自ターン開始、環境ダメージ | 確定 | 本編実装済 |

ラウンドは双方のターンを含む。上限の自然成長はなく、加速でのみ増える。封脈の補充妨害は上限を下げず、次の補充量を減らす（最低2）。

## CD・持続効果・計算順序

使用時 `readyOn = ownTurn + cd + 1`。CD1なら次の自ターン不可、その次に可。相手ターンへの移行でCDを不正に減算しない。
バリアは加算でき、次の相手ターン終了時に残量消滅。実ダメージを吸収し、HPへ通った量と区別する。

直接攻撃は条件付き基本ダメージ → 戦意・布石の攻撃強化と弱体を加減 → 0未満を0 → バリア吸収 → HP。
攻撃強化と弱体は対応する攻撃で消費する。弱体は攻撃せず終了しても残り、合算可能。
戦意は同ターンの次の攻撃、布石は次自ターン初回攻撃が対象。対応ターンに攻撃しなければ強化は失効する。
毒継続ダメージはバリアを無視。毒刃・蝕心の直接攻撃部分は通常のバリア処理を受ける。
終了処理では当該ターンの強化整理、所有者の毒処理と勝敗判定、相手のバリア期限処理、行動者・ラウンド更新を行う。細かいイベント順の正本は戦闘エンジン。

## 消耗の最優先処理

1. 自ターン開始時に消耗を適用する。
2. HP0以下なら即決着。補充や行動を開始しない。
3. 生存していればその他の開始時処理（MP補充、予約効果など）。
4. 通常行動。

1〜11Rは0、12〜13Rは1、14〜15Rは2、16〜17Rは3。以降2Rごと+1。
`R >= 12 ? 1 + floor((R-12)/2) : 0`。双方同じラウンド番号を参照し、バリア無視。通常攻撃・毒・反撃と区別する環境ダメージであり、将来の被弾特性を自動発火させる仕様ではない。AIも同じ開始処理を先読みする。

## 第一紀の固定奥義《戦技の残響》（仮）

| 項目 | 内容 | 仕様状態 | 実装状態 |
|---|---|---|---|
| 枠 | 英雄の固定奥義。通常5スキルとは別枠 | 確定 | 未実装 |
| 効果 | 同じ自ターンに最後に使用した通常スキルの効果を再演 | 確定 | 未実装 |
| 発動回数 | 1戦闘に1回 | 確定 | 未実装 |
| 通常行動 | 消費せずに発動する | 確定 | 未実装 |
| 再演元のMP/CD | 追加消費しない | 確定 | 未実装 |
| 元スキルの使用条件 | 再演時に再チェックしない | 確定 | 未実装 |
| 効果の計算 | 再演時点の戦闘状態に基づく | 確定 | 未実装 |
| 間に挟む操作 | 通常スキルと奥義の間にマナ加速等を挟んでよい | 確定 | 未実装 |
| 参照期限 | 対象を次の自ターンへ持ち越さない | 確定 | 未実装 |
| 消費MP | 暫定1。必要に応じてMP2と比較 | 暫定／比較候補 | 未実装 |
| 名称 | 《戦技の残響》 | 暫定（仮称） | 未実装 |

「元のMPを追加消費しない」と「奥義自体が無料」は別。奥義自身の消費MPは暫定値を持つ。通常行動を消費しないという承認は、既存コアへ新しい行動回数制・AP等を導入する指示ではない。通常スキルの使用記録と奥義再演の区分も実装時に設計する。

**未確定**：毒を既に消費した場合の再演・消費順、対象選択、攻撃強化／弱体／履歴等との詳細相互作用、参照元がない場合の操作・表示、細かな勝敗やイベントとの接続。基本方針の「条件を再チェックしない」「再演時点で効果計算」は維持し、その細部を推測で決めない。直前のダメージ数値を単純複製する仕様とも決めつけない。

戦旗の既存研究にある「再演時に条件を再チェックし、条件消失なら不発」は英雄奥義とは別の仮ルール。両者を同じ再演API・条件仕様へ自動統合しない。王の権能の詳細は[ボス](bosses.md)で扱う。

戦闘途中のHP・MP・CDを保存しない方針と、初回勝利ログの保存は[進行・保存](progression.md)を参照。スナップショットAPIがあることを途中セーブの承認とみなさない。
