## 現行公開デモの概要・確定仕様

固定スキル制。自ターンにMPと使用条件を満たすスキルを任意順に使い、終了すると相手へ移る。HP0以下で直ちに決着し、残り行動を止める。通常攻撃力ステータス・ドロー・山札は使わない。

| 項目 | 現行条件 | 仕様状態 | 実装状態 |
|---|---|---|---|
| HP | 双方20、回復は最大HPまで | 暫定（デモ基準値） | 本編実装済 |
| 初手 | プレイヤー先攻MP2/3、ボス3/3 | 暫定（補正値） | 本編実装済 |
| 以降の補充 | 自ターン開始に上限まで、余剰持越しなし | 確定 | 本編実装済 |
| 加速 | MP2、同自ターン1回、次自ターンから上限+1、最大5 | 確定 | 本編実装済 |
| CD | 使用者の自ターン基準。CD0も同ターン1回 | 確定 | 本編実装済 |
| 毒 | 下記の新旧区分を参照 | 旧公開版と新承認を分離 | 旧処理のみ本編実装済 |
| 消耗 | 12Rから各自ターン開始、環境ダメージ | 確定 | 本編実装済 |

ラウンドは双方のターンを含む。上限の自然成長はなく、加速でのみ増える。補充妨害の個別効果・下限は[スキル正本](skills.md#old-catalog)を参照する。

## CD・持続効果・計算順序

使用時 `readyOn = ownTurn + cd + 1`。CD1なら次の自ターン不可、その次に可。相手ターンへの移行でCDを不正に減算しない。
バリアは加算でき、次の相手ターン終了時に残量消滅。実ダメージを吸収し、HPへ通った量と区別する。

直接攻撃は条件付き基本ダメージ → 攻撃強化と弱体を加減 → 0未満を0 → ボス固有補正（新版のみ）→ 小数点以下切捨て → バリア吸収 → HP。最低1ダメージの保証はない。新版の崩しへの加算位置は[bosses](bosses.md)を参照する。
攻撃強化と弱体は対応する攻撃で消費する。弱体は攻撃せず終了しても残り、合算可能。
強化の個別対象・期限は[スキル正本](skills.md#old-catalog)で管理する。
毒継続ダメージはバリアを無視。毒関連スキルの直接攻撃部分は通常のバリア処理を受ける。
終了処理では当該ターンの強化整理、所有者の毒処理と勝敗判定、相手のバリア期限処理、行動者・ラウンド更新を行う。細かいイベント順の正本は戦闘エンジン。

## 毒の共通ルール：新版・過去研究・旧公開版

| 適用範囲 | 共通ルール | 仕様状態 | 実装状態 |
|---|---|---|---|
| 過去研究（固定2の比較基準） | 持続ターン数で管理。固定2ダメージ／ターン。付与時は持続ターンを加算し、上限なし。毒を受けているキャラクターのターン終了時に発生し、バリアを無視 | 過去研究の検証条件。現行の承認設定とは区別 | 研究環境のみ。最新条件を置換しない |
| 新第一紀 `first-era-v1` | 付与加算、スタック上限8。対象のターン終了時、減算前の残数に応じて最大6ダメージを与え、その後残数を1減らす。残数0は発生せず、バリア・構え倍率を無視 | 今回の承認設定（調整可能） | コア実装済み／UI未接続 |
| 旧公開版・現行コア | 所有者の自ターン終了時に残数と同量のダメージを与え、残数を1減らす。上限4 | 旧公開版の確定条件。新プロトタイプでは置換 | 本編実装済 |

新版は終了時の強化整理・再演参照の失効→行動者の毒ダメージと減衰→即時勝敗判定→相手のバリア期限消滅→手番/ラウンド更新→開始処理の順。毒で決着したら期限処理・次ターンを開始しない。個別の毒付与/参照は[skills](skills.md#current-poison)。

同じ状態異常は独立タイマーを増やさず、actorの残数/量を加算する。毒は上限まで加算し、イベントに実付与量と加算後残数を記録する。弱体は加算して次の直接攻撃1回で全消費、攻撃しない限り残る。攻撃強化・布石も既存の加算と期限を維持する。毒tickは対象の自ターン終了1回につき1回で、付与回数分を別々に発動しない。

## 消耗の最優先処理

1. 自ターン開始時に消耗を適用する。
2. HP0以下なら即決着。補充や行動を開始しない。
3. 生存していればその他の開始時処理（MP補充、予約効果など）。
4. 通常行動。

1〜11Rは0、12〜13Rは1、14〜15Rは2、16〜17Rは3。以降2Rごと+1。
`R >= 12 ? 1 + floor((R-12)/2) : 0`。双方同じラウンド番号を参照し、バリア無視。通常攻撃・毒・反撃と区別する環境ダメージであり、将来の被弾特性を自動発火させる仕様ではない。AIも同じ開始処理を先読みする。
