# 構築・世代進行・保存

## 最新方針：第一紀は自由編成（2026-11-11承認）

新しい第一紀プロトタイプは**スキル自由構築型RPG**。通常スキル10種類から5つを選んで編成する。種類数10と編成数5は**確定／未実装**。10種類の具体的な内訳は**暫定／未実装**で、既存19スキルや新規研究スキルの採否を決定したものではない。

初期段階は解放ポイント・強化・試練を導入しない（**保留／第一紀初期の対象外**）。従来の3種スターター→ランダム習得5回という導線は、新版では**廃止・自由編成へ置換**。現在の公開デモを削除・変更する指示ではない。第一紀は老王への何度でも可能な再戦を持ち、通常5枠とは別枠の英雄固定奥義を使う。奥義の正本は[戦闘](combat.md#第一紀の固定奥義戦技の残響仮)。

新しい拠点・編成確定・戦闘へのUIを段階的にReactへ実装する。既存の習得・交換・リロール・スキップを、移行という理由だけで新導線へ実装しない。具体的な画面遷移や編成UIの細部は未決定。

## 保存方針（確定／未実装）

| 対象・契機 | 承認済みの方針 |
|---|---|
| 保存方式 | ローカル自動保存。当初1セーブスロット |
| 編成の保存 | 編成画面で「編成を確定」した時点。未確定の変更は保存しない |
| やり直し | 設定メニューから確認付きで最初からやり直せる |
| 再戦 | 老王へ何度でも再戦可能 |
| 初回勝利 | 初回勝利時の編成・勝利記録を固定。再戦で上書きしない |
| 詳細戦闘ログ | 初回勝利の詳細ログを保存し、将来の次世代AI分析へ渡せるようにする |
| 戦闘途中 | 第一紀プロトタイプでは途中のHP・MP・CD状態を保存しない |
| 形式・保存先 | セーブ形式をバージョン管理し、保存先をゲームコアから分離する |

Webの保存先は**localStorageを想定する方針**。将来のPC配布・Steam向けに差し替え可能な境界を設ける。保存キー・詳細スキーマ・具体的なバージョン番号・書込順・障害時処理・移行方式等は**未決定**であり、実装時に設計する。現行の戦闘snapshot/restoreやFX Labの設定JSONは、このゲーム進行用セーブの実装ではない。

途中セーブなしは初回勝利ログを保存しないという意味ではない。編成の確定保存、初回勝利の固定記録、将来AI用の詳細ログを区別する。再戦結果で固定記録を更新する設計にしない。リセット時に設定をどこまで保持するか等の細部も未確定。

## 世代継承（方向性確定／本編未実装）

第一紀の英雄は老王を討ち、次代の王となる。第二紀の戦王は第一紀の英雄と同一人物。次世代王は、前世代英雄が**初回勝利時に使用した通常5スキル**を継承する。初回勝利の編成を固定することと、実際の成功手順を詳細ログとして保存することを分けて扱う。

戦王は独立した戦旗を召喚し、継承スキルを再演する方向。英雄の奥義と王の権能はテーマ的に関連するが、同じ能力である必要はない。英雄奥義のルールを戦旗へ自動的に転用しない。

継承王AIは王の誕生時に初回勝利ログから成功手順・合法な代替手順を分析し、その後は固定する方針。具体的なアルゴリズム・戦旗数値・世代数は未確定。[AI](ai.md#将来の継承王ai2026-11-11承認)と[ボス](bosses.md)を参照。第二紀以降の詳細機能は第一紀プロトタイプの実装対象外。

従来合意の将来プレイヤー通常5＋継承専用1は**確定（将来の方向性）／本編未実装・第一紀初期の対象外**。研究の6枚比較は保持するが、新第一紀の通常5＋固定奥義を通常6枠と数えない。通常と継承で同IDを重ねない、継承枠をボスに混ぜない等の旧案は将来拡張の条件として保持し、今回の第一紀へ復活させない。強化・刻印コピーの範囲も未確定。

## 保護する旧公開デモの実装

以下は旧方針の実装事実であり、新版の要件ではない。

初期3種：速攻＝斬撃／疾走斬、中速＝重斬／牽制、毒＝腐蝕／斬撃。習得イベント5回を経て固定5ボスの1体へ進む。

| 項目 | 旧条件 | 仕様の適用範囲 | 実装状態 |
|---|---|---|---|
| 所持 | 重複IDなし、通常最大5 | 旧デモの確定条件 | 本編実装済 |
| 習得 | 原則3択、5回 | 旧デモ暫定・新プロトタイプでは置換 | 本編実装済 |
| 追加／交換 | 5未満なら追加、5なら1つ交換。取消で元画面へ | 旧操作仕様 | 本編実装済 |
| リロール | 1周計2回、イベント間持越し、新周回2へ戻る | 旧デモ暫定 | 本編実装済 |
| スキップ | 無制限、未選択でも選択後でも可、確認なし | 旧デモ暫定 | 本編実装済 |

リロールはイベントを消費せず選択解除。所持IDを除外し、同じ3択内は重複せず、直前候補以外を優先、候補不足なら直前候補も使う。スキップは編成・残数を変えず、最終回なら戦闘へ。全スキップで初期2スキルのまま進行可能。

現在のGameProgression.optionsは毒付与スキルの所持による毒参照スキルの候補制限を実装していない。旧依頼の記述から独自制限を推測しない。新版の自由編成での条件警告や制限は別途検討し、旧抽選の問題をそのまま新版要件にしない。
