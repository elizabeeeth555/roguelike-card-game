# 世界観・素材

## 確定した世界設定

現実そのものが崩壊する災厄が進行する。老王は災厄を封じ込めているが、第一紀の英雄は知らずに老王を倒し、王座の役割を受け継ぐ。
各紀は同じ城・同じ王座。王の魂は王座へ縛られるが、戦闘では立ち上がれる。後代は前代の記憶の断片を受け取り、王座の力は個人の本質に応じた能力として発現する。
これらは今回の最新ユーザー指示による**確定設定**であり、物語イベントが本編実装済みという意味ではない。

## 第二紀の採用デザイン（確定／実ファイル対応は未確認）

- 英雄と戦王は同一人物。灰金色の髪、古びた装備、故郷の紋章。
- 戦王は長髪、片目の魔術的装飾、蒼いマント。王冠は付けない。
- 故郷の紋章は黄金の樹と放射状の意匠。
- 戦旗は深い蒼色、黄金の樹紋、二股の布、黒鉄の旗竿。戦王とは独立素材。
- 第一紀と第二紀で王座前の石段の段数・形状・位置関係を保つ。
- 第二紀は天井の大規模崩壊、回廊と壁の非対称な崩れで年月・災厄を表す。
- 第二紀の王座イベント絵と戦闘背景は同一構図。戦闘背景は王・装備を取り除いた空の王座。

チャットで採用された画像とリポジトリの同一性を確認できる対応表・ハッシュはない。既存の騎士／賢者素材を専用戦王／老王の完成素材と認定しない。新規生成・仮パスの捏造はしない。

## BGM・SEと権利

道中はWhispers in the Fog（Ruhinre）、戦闘はDetermined Pursuit（Emma_MA、CC0）。翡翠の双刃へ現曲を割り当て、残り4ボスの専用曲は未収録で既存曲へフォールバックする。
出典：[Determined Pursuit](https://opengameart.org/content/determined-pursuit-epic-orchestra-loop)。本整理では再試聴・配布先への再照会をしていない。詳細な出典と加工は同梱ライセンスを優先する。
ボスID別パス・音量補正を管理し、必要曲だけ再生、MP3フォールバック、失敗でも進行を止めない。
購入素材はGit・公開対象外。private-assetsを保護し、ファイルを外部へ送信しない。権利不明素材や有料素材を文書整理に伴って追加しない。
