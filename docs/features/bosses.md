# ボス仕様

## 第一紀・旧版・研究の適用範囲

新第一紀プロトタイプのメインボスは**《灰鎖の老王》に確定**。旧classicの固定5ボスは保護する実装であり、新版のメインボス一覧と混同しない。老王の数値は調整可能な暫定値。共通戦闘コア・React第一紀に接続済み、PR #28で公開ルートのソースへ反映済み（実際のPages配信・人間の実機操作は別途未確認）。

第一紀の英雄が老王を討ち、次代の王となる。第二紀の戦王は英雄と同一人物で、前世代英雄の初回勝利時に使用した通常5スキルを継承し、独立した戦旗で再演する方向。英雄固定奥義と王の権能はテーマ的に関連するが、同一能力を要求しない。第二紀以降の詳細機能は第一紀プロトタイプの実装対象外。

## 灰鎖の老王

**新仕様：2026-11-15のユーザー合意により、固有能力は《断誓一閃》1種類へ置換。仕様の基本方針・発動周期・予告・防御可能性は確定、威力とHP・難易度は暫定／検証中。実装状態：`feat/ashen-king-finisher-core`で戦闘コア実装済み、main未反映。UIの旧表示撤去・新演出は依存ブランチで別工程。** 旧main実装を新仕様とみなさない。

魂を王座に縛られ災厄を封じる先王という世界観、第一紀ボスとしての採用は維持する。通常所持スキルは斬撃・重斬・大振り・牽制・戦意（英雄の採用10種とは別の所持セット）。個別スキル性能は[スキル正本](skills.md)、英雄・老王のHP/MPは[戦闘正本](combat.md)を参照する。通常スキルの再調整は未決定。

### 固有能力《断誓一閃》（新仕様）

| 項目 | 内容・仕様状態 |
|---|---|
| 能力数 | **《断誓一閃》のみ**（確定）。専用の構え・崩しゲージを持たない |
| 初回 | **老王の2ターン目**に発動（確定） |
| 周期 | 初回以降**3ボスターンごと**。2・5・8・11…ターンで発動（確定） |
| 行動 | 発動する老王ターンは**通常スキル行動の代わりに**一閃を1回行う。通常行動を追加しない（確定） |
| コスト・記録 | MP0、CDなし。通常スキルの所持・使用済み・攻撃履歴・CDへ記録しない（今回承認・コア実装） |
| 攻撃 | 単体への通常の直接攻撃としてダメージ処理。**バリア吸収・牽制の弱体が有効**で、旧構え倍率・崩し条件は適用しない（確定） |
| 威力 | **基本8ダメージ（検証用暫定値）**。最終性能は実測後に調整 |
| 予告 | 発動**直前の英雄ターン開始時**に「**老王は力を溜めている**」と表示（確定）。英雄先攻のため初回は英雄2ターン目の開始時 |
| チャージ演出 | 予告した英雄ターン中、老王が力を溜めていることを視覚的に明示（確定）。表示と演出の共通規則は[UI正本](ui.md#ashen-king-charge-preview) |

**設計目的**：初回ボスでは複雑な固有リソース管理や毎ターンの崩しノルマを課さず、予告された大技に対して攻撃・防御・回復・毒などの戦術を選べるようにする。1戦につき**一閃1〜2回程度を観測することをバランス目標**とするが、速攻撃破等で発動前に終わることは許容し、発動回数を強制するHPロック等は設けない。これは検証目標であり、保証条件ではない。

**廃止（現行仕様に適用しない）**：旧《不退の誓約》の不退／断誓の交互構え、直接被ダメージ75%軽減／1.5倍、崩し閾値4・蓄積／崩しによる一閃阻止、旧一閃5ダメージ・構え遷移時の発動条件。旧実装・過去研究レポートは履歴として保護するが、新第一紀の仕様には参照しない。

**コア接続（専用ブランチ実装済み）**：能力ID `ashen_king_finisher`、合法行動`ability`、`bossAbilityStatus`で周期・1回制限を判定。`bossWarning`は英雄ターン開始後、`bossAbility`→直接ダメージ→必要なら決着の順。状態`bossState.charging/flashUsedTurn`は描画へ公開。能力後はターン終了のみ合法。AI-2は同じ合法手列を利用し、評価式・探索幅は変更しない。旧第一紀ログ互換は今回承認で廃止し、保存更新は[進行](progression.md#playable-save-flow)へ記録する。UI接続は別工程。

## 誓旗の戦王

**確定した方向**：第一紀の主人公が王となった同一人物。人格は継続し、王座の力で前代通常スキルを再演する戦旗を召喚する。
旗は独立した攻撃対象、破壊で再演阻止、ボス追加ペナルティなし。通常スキル継承・再演の試作は研究環境のみ。

| 比較条件 | 旗HP | 召喚 | 状態 |
|---|---:|---|---|
| A | 1 | 毎ボスターン | 検証中／研究環境のみ |
| B | 1 | 隔ボスターン | 検証中／研究環境のみ・第一候補 |
| C | 1 | 毎ターン、破壊後の次回1回休止 | 検証中／研究環境のみ |
| D | 2 | Cと同じ | 検証中／研究環境のみ |

研究のボス自ターンnを初期召喚n=0から数える。初期旗はn=1で再演、Bの後続召喚はn=2/4/6…のみ。C/DでP1が初期旗を破壊した場合、B1で休止しB2で召喚、生存ならB3で再演。
研究の開始順は消耗→通常開始更新→古い旗の再演／不発→旗消滅→新召喚判定→通常行動。候補0でも空の旗を出すのは仮定。旗に対する余剰ダメージは本体へ流さない。
開始時初回召喚は通常行動を消費しない。後続召喚無料は研究上の仮定。戦王HP等も暫定。
召喚時に発動条件を満たす前代通常スキルから抽選・公開。別候補があれば直前抽選IDを除く。
残った旗は次ボスターン、通常行動より前に再演。MP・CD・使用済みを無視し、再演時に条件が消えていれば不発。通常使用履歴と混同しない。
対象選択はスキル選択→使用→本体／旗。旗は状態異常無効。複合攻撃の直接部分と無効な追加効果を分ける。細部は検証中。
英雄固定奥義の基本仕様は[スキル正本](skills.md#first-era-ultimate)で確定しているが、王への奥義継承・戦旗による奥義再演は未検証・未実装。今回の通常5スキル継承と混同しない。

研究の現表示（旗が右、王中央）を採用済み配置とみなさない。
予告表示A＝旗下／B＝中央情報窓／C＝名前のみの比較は研究環境のみ。最終案は要確認。**召喚周期Bと予告UIのBは別の比較軸**。
第一紀老王の旧崩し専用ゲージは新仕様で廃止。専用素材は削除せず台帳へ保持する。予告・チャージ演出の表示方針は[UI正本](ui.md#ashen-king-charge-preview)を参照。
