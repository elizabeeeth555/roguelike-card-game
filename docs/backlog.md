- 通常カードは原則**1枚につき強化1回**。世代別強化グレードは累積する成長段階ではなく、その世代で行った1回強化の完成形として設計する方向。

- 数値増加より条件付きシナジー・役割の拡張を重視するが、**全35種類のバランス検証は未実施**。

## 継承の方向【合意済み／新版では未実装】

前代の通常デッキが次代ボスとなり、次代プレイヤーは通常デッキから選んだ1枚を別の継承専用枠へ受け取る。
通常5枚と継承1枠を分け、同一カードIDの重複は基本的に禁止する。

| 要素 | 次代ボスへの扱い | 状態 |
|---|---|---|
| 前代の通常デッキ | 構成・強化・刻印などを保持 | 方向性合意、新ルールへ未導入 |
| 継承専用枠のカード | コピーしない | 合意済み |
| パッシブ | 取得能力を引き継ぐ | 機能自体が未実装 |
| 枷 | メリット・デメリット両方を引き継ぐ | 機能自体が未実装 |
| 必殺技 | 引き継がない | 通常カードの切り札とは別概念、未実装 |
| 周回固定のボス固有能力 | 前代の取得能力とは別に付与 | 方向性合意、効果・値は再検証 |

旧版では、その時代の通常カードから選び直し、前代から持ち越した継承カード自体は再継承候補にしなかった。
新ルールの継承実装時にもこの制約を採用するか、専用強化との相互作用を含めて明文化する。
キャラIDとデッキは分離し、同じ人物の背面／ボス正面のポーズだけを切り替えられるようにする。

## カード強化【方針と未承認案を区別】

- 1枚への無限な数値集中より、カード獲得・組合せ・ビルド変更を重視する。
- 通常カードは1枚につき1回の強化を基本とする方向。強化／改／真強化／覚醒の具体効果・各世代の適用条件は未確定。
- [35種の強化効果草案](#draft-upgrades)は未レビュー・未承認。自動採用しない。
- 継承カード限定の二段階目強化は専用イベントで行う構想。元が未強化の場合、適用グレード、回数・頻度は未確定。
- 通常強化や継承専用強化の情報を、次代ボスへコピーする通常デッキのスナップショットに混ぜない。

## 能力と構築イベント【未実装】

- パッシブ：常時効果による個性化。取得数・イベント頻度・効果は未定。
- 枷：デメリット、またはメリットと代償の組合せ。解除条件・効果は未定。
- 必殺技：通常カードと別枠の任意発動、原則1戦闘1回、1種類装備の方向。マナ不要は未確定。
- カード変異：通常カードを別カードへ変える案。未強化カードを変異させると強化済みにする案があるが、変異先プール・状態保持・刻印・継承との重複制限は未定。
- 独立した「カード交換イベント」は不採用。獲得上限時の入れ替え操作とは区別する。

世代倍率（例：累計×1→×10→×200→×6,000→×240,000）は構想上の値で、採用決定ではない。
最終章、初代ボスの真の姿、過去の継承カード回収も長期構想。
