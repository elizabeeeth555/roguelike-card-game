# 将来のカード強化効果：第二紀「強化」35種類の未承認案（参考用）

**今回は絶対に実装しない。** この文書は過去のチャットで提案された**未レビュー・未承認の強化案**を失わないための記録。基本カードA〜H（計35種）の未強化効果と混同しないこと。第三紀以降の「改／真強化／覚醒」の具体効果も未確定。

## 共通方針の草案

- 通常カードは原則**1枚につき強化1回**。世代別強化グレードは累積する成長段階ではなく、その世代で行った1回強化の完成形として設計する方向。
- 強化＝カード本来の役割を伸ばす／改＝他カードと連携／真強化＝新しい勝ち筋／覚醒＝高い条件・大きな効果、という**デザイン方針**が提案された。
- 数値増加より条件付きシナジー・役割の拡張を重視するが、**全35種類のバランス検証は未実施**。
- 以下の「追加効果」は**第二紀のグレード「強化」の草案**。今回の第一紀カードには一切適用しない。

## A. 共通（6）

| カード | 強化草案：基本効果に追加 |
|---|---|
| 斬撃 | 敵にバリアがある場合、バリアへのダメージ+2 |
| 重斬 | 敵HPが半分より多ければ+1ダメージ |
| 大振り | 敵にバリアがある場合、バリアへのダメージ+2 |
| 結界 | 実際に1以上防いだら、次の自ターン初回攻撃+1 |
| 堅守 | バリアをすべて消費したら、次の自ターン最初のカードのコスト−1 |
| 手当 | 実際に回復できたら、自分の毒−1 |

## 今後のレビュー課題

- 先にA〜Dの**未強化での実測バランス**を確認する。
- バリア貫通効果の重複、CT・行動順、強化発動タイミングを定義する。
- 「改／真強化／覚醒」は**具体効果未決**。上の強化案を次グレードへ自動的に繰り上げない。
- 同名の強化前後・世代別名称違いは原則同カードID扱い、デッキ重複不可。
