# 第一紀・新戦闘検証版の確定事項

2026-11-06。実装パッケージの仮置きを、チャットで一件ずつ確認した結果。
優先順位は最新ユーザー指示 → 本文の確認済み事項 → パッケージの確定・検証採用 → 旧仕様。
受領時の資料は正式な仕様・将来案・履歴へ整理済み。[設計資料の入口](README.md)を参照。

1. マナは予約した上限増加を反映 → 新上限まで補充 → 妨害減算（最低2）。加速したそのターンは上限も使用可能マナも増えない。
2. 初期ビルドは速攻「斬撃＋疾走斬」、中速「重斬＋牽制」、毒「腐蝕＋斬撃」。
3. プレイヤーは黒剣士。敵は防御＝重装騎士、毒＝魔女、高火力＝大男、速攻＝斥候、テンポ＝賢者。キャラとデッキの定義は分離。
4. 攻撃弱体は同種も合算し、次の攻撃カード1枚で消費。攻撃しなければ持ち越し、ダメージ0でも消費。
5. 即時ダメージを持つカードはすべて攻撃タグ。牽制・封脈・布石・毒刃・蝕心・呪詛を含む。使用成立なら0ダメージでも攻撃に数える。毒付与・終了時毒tickは数えない。
6. 攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合カードは攻撃色と複合タグの文字を併記。
7. 戦意＋布石は同じ攻撃に合計＋5。条件込み基本ダメージ＋バフ−弱体（最低0）→バリア。対象ターンに攻撃しなければバフ失効。
8. 勝敗どちらの結果画面にも「同じ条件で再戦」「最初から」を用意。前者は同じデッキ・同じプリセットで戦闘を初期化、後者はビルド選択からやり直して次のボス戦で再抽選。
9. 最新の画像指示に従い、**大男・斥候の画像は使わない**。デッキは除外せず、画像設定を無効にして代替表示。他4キャラの12PNGを仮素材として使用。採用した原画像12枚は改変せず正式配置。不要な入力パッケージと不採用素材は整理時の最新指示に従い削除。

## 固定するルール

- 第一紀のみ、双方HP20。初期2枚→3択獲得3回→通常5枚→ボス1戦。
- A〜Dの19カード。強化・継承・旧切り札・E〜H・第二紀以降の進行は出さない。
- 初期上限3、先攻初回2/3・後攻3/3。加速は2消費・各自ターン1回・最大上限5。
- CDは本人の自ターン基準。CD1は次の自ターン不可、CD2は次の2自ターン不可。
- 毒は0〜4。本人終了時に現在値のHP直接ダメージ→1減少。通常の毒消費攻撃はバリアを無視しない。
- バリアは付与後の次の相手ターン終了で残量消去。
- 継承専用枠・ボス固有・プレイヤーパッシブは予約表示だけ。
- カード数値・HP・コストはパッケージ値。数値調整は今回行っていない。
