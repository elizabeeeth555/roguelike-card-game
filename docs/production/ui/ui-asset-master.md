## この資料の役割と反映状況（2026-11-15照合）

本資料が管理するのは**UI-001〜072の制作・検証候補と作業整理**のみ。表示ルール・承認状態は[UI正本](../../features/ui.md)、スキル・ボス個別仕様は各正本、42枚の素材番号・ハッシュ・パス・実装／配信状態は[素材台帳](../../assets/ui-image-inventory.md)を参照する。番号「UI-029」と素材「29番」は別体系で、対応を推定しない。以下の優先度・方式は未承認の提案で、実装許可や最新ロードマップを意味しない。

- **main反映済み**：2026-11-15に[PR #30](https://github.com/elizabeeeth555/roguelike-card-game/pull/30)がマージされ、登録PNG原本42枚、配信用WebP33枚、第一紀Reactへの素材接続とUI配置修正がmainへ入った。33枚のWebPは配信用派生、残り9枚は非配信の原本として保持。公開ジョブ成功と人間の実機評価は区別する。
- **既存表示**：第一紀Reactの通常5枠＋奥義、スキル詳細の小型／拡大、MP・CD・HP、敵側の鎖などは実装が存在する。旧崩し表示もコードには残るが新第一紀では廃止・撤去対象。ただしPCでの人間の可読性／デザイン評価、未登録のスキル**専用詳細イラスト**、一部状態・ボス固有能力アイコンは別課題。
- **将来・保留**：スマホ縦画面の全面的な新規デザインは2026-11-13承認のPC優先方針で停止中。ただし2026-11-15承認の**ボス固有能力アイコンのタップ詳細**はPCホバーと同時に実装する優先項目（[UI正本](../../features/ui.md#boss-ability-detail)）。王座工房の共通React表示部品は継続利用し、工房編集機能の拡張は後工程。
- **進捗管理**：個々の素材の「登録・採用・実装・配信」をこの一覧へ二重転記せず、上記台帳と[状態資料](../../status.md)で確認する。UI-001〜072の制作項目全体は一括して「未制作」とみなさず、未照合項目だけ個別確認する。

## 分類と優先度

- **画像**：画像生成・既存原画の加工が主体。
- **コード**：React/TypeScript、CSS、SVG、JSで生成・制御。
- **併用**：装飾画像とコードを合成。CSS/SVGで同等品質なら画像は省略可能。
- **P0〜P3** は2026-11-13時点の制作検討用ラベル（P0＝共通部品・操作、P1＝第一紀の見た目、P2＝演出・拡張、P3＝後続画面）。**最新の作業順序ではない**。実装済項目も当時のP値を残す。新規スマホ縦デザインは「保留」と明示する。優先順位の判断は[status](../../status.md)と新しいユーザー承認を優先する。

**UI-001以降のIDはこの台帳だけの制作管理番号。** スキルID・実ファイル名・コンポーネント名ではない。1項目が複数画像を含むことがある。

## 制作・管理ルール

1. **画像に文字・数値・技名を焼き込まない。** 変動する表示はゲームデータ＋Reactで描く。
2. 枠・アイコンは**現行のSVG viewBox／CSS表示と原本保持**を前提にする。9-slice／border-imageは将来の選択肢であり、現行の確定実装方式とはみなさない。
3. 共通デザインは黒鉄・鈍い古金、操作可能な部品だけ装飾を強める。HUDは原則枠なし。分類色はUI正本を参照。
4. 透過素材はアルファと縁を確認。採用原画の同一性・ライセンスを確認し、購入・非公開原本はGitへ登録しない。既存の`/private-assets/`除外を尊重。
5. 画像・コード・併用の分類は**実装方式の提案**。王座工房で寸法・配色・表示時間を調整する。
6. PC 1920×1080を構図基準とし、1366×768・1280×720の可読性・操作を検証する。スマホ縦の全面的なデザイン調整は行わない。ただしボス固有能力のタップ詳細はPCと同時に検証する。
7. 実装済みの旧公開版・React技術検証・研究結果を新第一紀の完成とみなさない。素材の採用・本編実装・公開反映を別管理する。
8. FX/SEは既存制作マスターを参照。新たなボス能力・スキル仕様をこの資料で定義しない。
