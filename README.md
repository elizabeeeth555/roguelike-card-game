# 継世の戦闘 — 第一紀・新戦闘ルール検証版

短い道中で最大5枚の固定手札を構築し、5種類のボスのいずれかと戦う静的Webゲーム。
今回は第一紀のみ。スキルの組合せ・CD・マナ加速・毒のバランスを検証します。
次のバージョン番号は未確定のため、package.jsonの番号は従来の0.9.5を保持しています。

## 起動

`index.html`をChromeまたはEdgeで開いてください。ビルド・インストール・サーバーは不要。
GitHub Pagesでも同じ構成で動きます。`src/`と`assets/`を同じ階層に配置します。

## 今回のルール

- 初期ビルド2枚 → スキル獲得イベント5回（追加・入れ替え・スキップ） → 通常2〜5枚 → ボス1戦。
- 通常スキルはA〜Dの19種。強化・旧切り札・継承・第二紀以降の進行はありません。
- 双方HP20、攻撃力ステータスなし。印字値と条件でダメージを計算します。
- マナ上限3。先攻プレイヤーの初回だけ2/3、後攻ボスは3/3。
- マナ加速は2消費・各自ターン1回。次の自ターンから上限＋1、最大5。
- スキルは各自ターン1回。結界・堅守はCD1。CD1は次の自ターン、CD2は次の2自ターン使用不可。
- 毒は最大4。毒を持つ本人のターン終了時に現在値のHP直接ダメージ、その後1減少。
- バリアは次の相手ターン終了時に残量消滅。弱体は次の攻撃まで持ち越し、合算して消費。
- 結果画面は「同じ条件で再戦」と「最初から」。再戦は同じ5枚・同じボスで戦闘状態を初期化。

スキルは攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合スキルには文字タグも表示します。
PC・スマホともスキルを選んでその場で詳細を拡大し、選択スキル直下の「使用する」で確定します。敵スキルは効果確認専用です。自分の演出中は次の選択のみ可能で、追加使用・加速・ターン終了は待機します。
数字キー1〜5はスキル詳細、Spaceはターン終了。拡大は敵味方を通じて1枚だけ。
右上の設定から演出速度・最初から（確認あり）、音量からBGM/SEを変更。ログは右端中央の独立タブで開閉。ターン演出はクリック・タップ・Enter/Spaceでスキップできます。

## 画像・音声

PCは中央にボス、左下に顔付きプレイヤーHUD。敵5枚を常時公開し、下部に手札と操作を配置。ログは右ドロワー。スマホは敵が上、自分が下。
通常5枚とは別の継承枠、ボス固有、プレイヤーパッシブは説明付きの予約表示のみです。
ユーザー提供の6人の立ち絵を採用。正式PNG原本は`assets/characters/masters/`、透過した立ち絵・顔・バストアップは`assets/characters/castle/`に保存しています。
大男・斥候も新素材を使用し、5ボスのスキル構成は維持。読み込み失敗時は代替表示で進行できます。
道中は古城の回廊、戦闘は玉座の間の背景。原本PNGと配信用WebPを`assets/backgrounds/`に保存しています。

画像・背景・音源は`assets/asset-map.js`で管理。既存SVGと音源は保持しています。
BGMは道中Whispers in the Fog、戦闘Determined Pursuit。BGM/SEのON/OFFと音量変更に対応。
出典・配布条件は`assets/sounds/README.md`を参照してください。

## 開発・検証

```powershell
npm test
npm run check
npm run test:browser
npm run simulate -- 10
```

通常テストはNode.jsのみで実行できます。Chrome検証はインストール済みChromeを使用。
`CHROME_PATH`で実行ファイルを指定できます。依存パッケージのインストールは不要です。

- 自動テスト：新19スキル、先後手・CD・毒・バリア・妨害、AI、導線・再戦・中断・画像除外。
- 旧仕様のテスト：隔離した`src/game/legacy/`を対象に、旧スキル624ケース等を維持。
- 構文検査：`src/`・`assets/`・`scripts/`・`tests/`の全JS/CJS。
- Chrome：file://で起動し、PC1366×768とスマホ360×800・390×844・430×932を確認。
- シミュレーション：3ビルド×5ボス×10シード。双方AI・報酬は固定シードの乱択で、人間の勝率とは異なります。

スクリーンショット・検証JSONは`.test-artifacts/`へ出力します。ゲーム内にターン制限はありません。
防御型の長期化や相性差は継続観察対象で、スキル値を自動調整しません。
実機タッチ操作・音声の聴感・素材の残る切り抜き品質は別途確認が必要です。

### 正式PNG・ボス拡大・敵スキル小型化

最新6人の1024×1536 PNGへ差し替え。透過済み5枚の戦闘用画像は原本と完全一致、魔女だけ修正後RGB原本から背景除去。旧JPEG由来の派生物は差し替え済み。

## 最新反映（2026-11-07）

正式採用・本体反映：結界/堅守CD1、AI-2（上位8＋加速/布石各最大2候補）、12Rから各自ターン開始の消耗ダメージ。毒は終了時を維持。
デモ暫定：獲得イベント5回、上限5枚で入れ替え、周回合計2リロール、無制限スキップ。全スキップなら初期2枚で戦闘可能。新周回は回数初期化。
AI-L/AI-D/AI-4、幅24、探索延長、強化/特性/継承6枚目は未実装。詳細は `docs/specs/first-era/11-ai-exhaustion-draft.md`（リポジトリルート基準）。過去研究は当時の条件として保持する。

`npm run simulate` は従来の3回抽出で固定5枚を作る戦闘ベンチマークを維持。5イベントの操作導線はブラウザ回帰テストで検証する。

## スキル構築型RPGのUI（2026-11-07）

現行の方向性はスキル構築型ローグライクRPG。最新UI仕様は `docs/specs/first-era/12-skill-ui.md`（ルート基準）。スキルのMP/基本CDを独立表示、使用済/CD中は排他、詳細は効果全文のみ。習得詳細のリロール/スキップは通常画面へ集約。BATTLE STARTとターン演出、毒・数値演出、HUDを改善。内部card/deckは互換性のため維持する。戦闘・習得ルールは前回の採用仕様から変更しない。

## 戦闘演出・交換UIの更新

選択パネルを固定し詳細だけ位置補正。交換時は効果確認と交換確定を分離し、キャンセルを独立配置します。設定から標準/軽量エフェクトを選べます（保存/OSの動き軽減対応）。通常速度は従来の高速を基準に短縮。
詳細は[現行演出仕様](docs/specs/first-era/13-combat-presentation.md)を参照。ボス別BGM切替基盤は実装済みですが、新曲4曲は配布元確認ができず未収録です。既存曲がフォールバックします。

## 開発用 FX Lab（ローカル専用）

ゲームを起動せず、FXとSEの再生・調整・A/B比較・JSON保存を行えます。
リポジトリルートで `python -m http.server 8000 --bind 127.0.0.1` を実行し、
[http://localhost:8000/dev/fx-lab.html](http://localhost:8000/dev/fx-lab.html)を開いてください。
追加依存・クラウド・APIキーは不要です。[操作と対応形式](dev/README.md)。
購入素材はファイル選択で開き、`private-assets/` や素材本体をコミットしないでください。本編・公開設定には影響しません。
