# 継世の戦闘 Phase 3 Ver.0.9.1 — UI・演出版

Ver.0.8 をベースに、**ゲームルール・HP・攻撃倍率・イベント数・AIのカード選択・継承の仕組みは変更していません**。今回の変更は表示、操作補助、戦闘アニメーションとSEだけです。

## プレイ・GitHub Pages公開

- ローカル: `index.html` をブラウザで開く。アセットはこのフォルダ構成のまま保持。
- Pages: ZIPを解凍し、`index.html` と `assets` フォルダを**リポジトリ直下**へアップロード。`README.md` は任意。GitHub Pages は `main` / `/(root)` で公開。
- **画像フォルダがない場合もゲーム本体は動く**よう、旧バージョンのCSS仮グラフィックにフォールバックします。

## 変更点

1. 敵の手札を戦場内に表示。使用開始時に金色に発光、使用後は暗転（敵ターン終了で初期化）。カードをホバー／タップすると効果が読める。
2. 敵のカードごとに発動前の一拍、攻撃・防御・魔法の演出。被弾数字、被弾時の自分のHP欄の強調。合成SEを種類別に追加（♪で有効化）。
3. 敵の初期守護者と第一紀・第二紀の英雄を異なる仮グラフィックに変更。第一紀の英雄は第二紀でボスになっても同じ外見。
4. ログは最新1件を常時表示、ボタンで詳細を開閉。ログ領域は固定高さで内部スクロール。
5. パッシブ／枷／必殺技／敵固有能力の**表示枠のみ**追加。実際の効果はまだ実装していません。アイコンはホバー／タップで説明。
6. 375〜430pxのスマホ縦画面とPC横画面を引き続きサポート。

## 素材の差し替え

**画像:** `assets/characters/guardian.svg`（第一紀ボス）、`era-1.svg`（第一紀英雄と第二紀ボス）、`era-2.svg`（第二紀英雄）を**同じファイル名**のSVGやPNG等に差し替える。拡張子や場所を変更したら `assets/asset-map.js` を書き換える。

**背景:** `assets/backgrounds/arena.svg`。同様に差し替え可能。

**SE:** `assets/sounds/` に好きな音源を置き、`assets/asset-map.js` の `sounds` へファイルパスを指定する。設定が空ならWeb Audioによる仮SEが再生される。

**カード絵:** 現時点では記号で仮表示。`assets/asset-map.js` の `cards` に `slash: 'assets/cards/slash.png'` のようにカードID別に画像パスを書けば戦闘画面のカード絵を差し替えられる（未登録なら記号）。
