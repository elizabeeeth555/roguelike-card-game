# 継世の戦闘 — 第一紀・新戦闘ルール検証版

短い道中で5枚の固定手札を構築し、5種類のボスのいずれかと戦う静的Webゲーム。
今回は第一紀のみ。カードの組合せ・CD・マナ加速・毒のバランスを検証します。
次のバージョン番号は未確定のため、package.jsonの番号は従来の0.9.5を保持しています。

## 起動

`index.html`をChromeまたはEdgeで開いてください。ビルド・インストール・サーバーは不要。
GitHub Pagesでも同じ構成で動きます。`src/`と`assets/`を同じ階層に配置します。

## 今回のルール

- 初期ビルド2枚 → 未所持の3択から1枚獲得を3回 → 通常5枚 → ボス1戦。
- 通常カードはA〜Dの19種。強化・旧切り札・継承・第二紀以降の進行はありません。
- 双方HP20、攻撃力ステータスなし。印字値と条件でダメージを計算します。
- マナ上限3。先攻プレイヤーの初回だけ2/3、後攻ボスは3/3。
- マナ加速は2消費・各自ターン1回。次の自ターンから上限＋1、最大5。
- カードは各自ターン1回。CD1は次の自ターン、CD2は次の2自ターン使用不可。
- 毒は最大4。毒を持つ本人のターン終了時に現在値のHP直接ダメージ、その後1減少。
- バリアは次の相手ターン終了時に残量消滅。弱体は次の攻撃まで持ち越し、合算して消費。
- 結果画面は「同じ条件で再戦」と「最初から」。再戦は同じ5枚・同じボスで戦闘状態を初期化。

カードは攻撃＝赤、防御＝青、回復＝緑、補助＝金、毒付与＝紫。複合カードには文字タグも表示します。
スマホではカードをタップして詳細を開き、「使用する」で確定。PCではカード下の使用ボタンも使えます。
数字キー1〜5はカード詳細、Spaceはターン終了。ターン演出はクリック・タップ・Enter/Spaceでスキップできます。

## 画像・音声

PCは左下手前の英雄の背面、右上奥のボス正面。スマホは敵が上、自分が下。
通常5枚とは別の継承枠、ボス固有、プレイヤーパッシブは説明付きの予約表示のみです。
大男・斥候の画像はユーザー指示で使用せず、代替表示にしています。5ボスのカード構成は維持。
他4キャラの12PNGは仮素材で、読み込み失敗時も代替表示で進行できます。

画像・背景・音源は`assets/asset-map.js`で管理。既存SVGと音源は保持しています。
BGMは道中Whispers in the Fog、戦闘Determined Pursuit。BGM/SEのON/OFFと音量変更に対応。
出典・配布条件は`assets/sounds/README.md`を参照してください。

## 開発・検証

```powershell
npm test
npm run check
npm run test:browser
npm run simulate -- 10
```

通常テストはNode.jsのみで実行できます。Chrome検証はインストール済みChromeを使用。
`CHROME_PATH`で実行ファイルを指定できます。依存パッケージのインストールは不要です。

- 自動テスト：新19カード、先後手・CD・毒・バリア・妨害、AI、導線・再戦・中断・画像除外。
- 旧仕様のテスト：隔離した`src/game/legacy/`を対象に、旧カード624ケース等を維持。
- 構文検査：`src/`・`assets/`・`scripts/`・`tests/`の全JS/CJS。
- Chrome：file://で起動し、PC1366×768とスマホ360×800・390×844・430×932を確認。
- シミュレーション：3ビルド×5ボス×10シード。双方AI・報酬は固定シードの乱択で、人間の勝率とは異なります。

スクリーンショット・検証JSONは`.test-artifacts/`へ出力します。ゲーム内にターン制限はありません。
防御型の長期化や相性差は継続観察対象で、カード値を自動調整しません。
実機タッチ操作・音声の聴感・素材の残る切り抜き品質は別途確認が必要です。
