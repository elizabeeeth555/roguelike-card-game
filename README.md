# 継世の戦闘 — Phase 3 Ver.0.8 (PC・スマホ両対応)

Ver.0.7のゲームロジックを維持し、画面幅760px以下でスマホ向けのレイアウトに切り替える試験版です。
PC画面ではこれまでの横画面UIを使用します。

## ローカル動作
`index.html` をChrome/Edgeなどで開くだけです。サーバーもAPIキーも不要。

## GitHub Pagesへの公開（最短）
1. GitHubで **Public** リポジトリ（例: `roguelike-card-game`）を作る。
2. この`index.html`をリポジトリ直下へアップロードしてコミット。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** にする。
4. ブランチは `main`、フォルダは `/(root)` を選んで **Save**。
5. 公開URLは `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` の形式。

※GitHub Freeの場合、GitHub Pages利用にはパブリックリポジトリが必要です。
※公開URLは誰でも閲覧可能。パスワードやAPIキー、個人情報、未公開の素材を含めないでください。

## 今回の変更

- 手札は横スワイプで閲覧し、タップで使用。操作の仕組み自体は従来どおり。

- 道中カード選択と強化比較もスマホ向けに表示を調整。
- 既存のカード効果・戦闘処理は変更なし。
