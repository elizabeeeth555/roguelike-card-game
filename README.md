# 継世の戦闘 — Ver.0.9.5

**第三紀追加・強化制限・敵固有能力を実験する試作版。** Ver.0.9.4のHTML/CSS/JavaScript分離構成を維持し、BGM/SEとPC・スマホ用UIも同梱しています。新たな効果と数値は**テスト用の仮仕様**です。

## 起動方法

ZIPを解凍して `index.html` をChromeまたはEdgeで開きます。`src/` と `assets/` は `index.html` と同じ階層に置いてください。ビルド・インストール・サーバーは不要。GitHub Pagesにも `index.html`、`src/`、`assets/` をリポジトリ直下に置けば公開できます。

## Ver.0.9.5の変更点

| 項目 | 実装内容 |

| 後攻マナ補正 | 敵は**第1ラウンドだけ2マナ**、第2ラウンド以降は従来どおりラウンド数に応じて増加 |

| 第三紀の強化 | 未強化の通常カード1枚を1回だけ**強化・改**（従来のレベル換算で`+2`）。刻印も1回分としてカウント |

### 第三紀の新しい通常カード（仮数値）

- 星火 — 低コストの固定ダメージ
- 破戒 — 敵の軽減・固有バリアを破壊して攻撃
- 残火 — 毒を付与する
- 魔力脈動 — 使用ターン中のマナを回復
- 癒しの詠唱 — HPを回復
- 一騎討ち — 中コストの直接攻撃
- 雷閃 — 固定ダメージの多段攻撃
- 静寂 — 敵のマナと攻撃を妨害

切り札は、第三紀では既存の「逆境の一撃」を暫定使用します。カード獲得時は通常デッキ上限5枚に達していても、既存カードと入れ替えるか新カードを破棄できます。継承枠は通常デッキ枚数に含めません。

### 強化と継承の注意点

- 同じ通常カードに**通常強化と刻印を重ねることはできません**（どちらも1回の強化として扱います）。
- 第二紀から引き継いだ強化済みカードは、第三紀ボスでその状態を維持します。
- 継承枠のカードは道中の通常強化イベントで選択できません。以前検討した**継承カード限定の二段階目強化**は今回未実装です。
- 第三紀「強化・改」は今回数値面で単純に大きくしています。カードバランスの本格見直し・世代ごとの桁インフレは**今後のバージョンで検証**します。
- パッシブ能力、枷、独立した必殺技の獲得・引き継ぎは未実装。画面上のアイコンは仮表示のままです。ボス固有能力のみ実際に発動します。

ゲームルールとブラウザの進行・表示を分離しています。ReactやNode.jsへの移行に向けた共通コアの使い方は [docs/architecture.md](docs/architecture.md) を参照してください。現在もビルド不要で、直接起動できます。

BGMは道中 **Whispers in the Fog**（Ruhinre）、ボス戦 **Determined Pursuit**（Emma_MA）。サウンド素材の参照先は `assets/asset-map.js` に集約しているため、画像・BGM・SEを後から入れ替えられます。著作権・配布条件については原配布元と `assets/sounds/README.md` を参照してください。

## VS Code・GitHubへ反映

1. すでにクローン済みの `roguelike-card-game` をVS Codeで開く。
2. 変更をコミット／退避してから、ZIPの中身を**リポジトリ直下**に上書き配置する。
3. `npm test` と `npm run check` を実行する（Node.jsが必要。ゲーム起動には不要）。
4. PC・スマホでゲーム進行を確認し、コミット・プッシュする。既存のGitHub Pages URLで最新版を配信できる。

## テスト・留意事項

- `npm test`：**28件の自動テスト**。変更前の全カード624ケースとの比較、回復、軽減、毒、切り札、敵マナ、AI、強化、継承、三世代進行、入れ替え／破棄操作、JSON状態往復、演出中断、全スクリプトの読み込みを検証します。
- `npm run check`：`src/`・`assets/`・`scripts/`・`tests/`の全JavaScript構文チェック。
- テスト環境におけるブラウザ起動制限により、今回のブラウザ実機による視覚・音声確認は未実施です。PC・スマホの実機で、特にターン演出のスキップ、第二紀ボスのバリア、第三紀の継承、BGM/SEを確認してください。

Ver.0.9.5は**完成したゲームバランスではなく、固有能力と強化制限の体験を確認するための版**です。HPやカード威力、3面の固有能力数値はプレイ結果を踏まえて見直します。
