# 継世の戦闘 Phase 3 Ver.0.9.2

**Ver.0.9.1をベースにした、敵の行動演出・スマホUI・切り札テスト版。** 既存カードの数値・基本的な戦闘ルールは維持。カード数・イベント数・新切り札の倍率はすべて実験用。

## 起動方法

- PC: ZIPを解凍して **`index.html`** を Chrome / Edge で開く。`assets/` は `index.html` の隣に置いたままにしてください。
- スマホ: GitHub Pages公開がおすすめ。`index.html` と **`assets` フォルダを含むすべてのファイル**をリポジトリのルートに配置し、Settings → Pages で **Deploy from a branch → main → /(root)** を指定。
- ブラウザでの利用にサーバーやAPIは不要。進行状況の自動保存はありません。

## Ver.0.9.1 からの変更

### バグ修正・操作改善

1. **戦闘をまたぐ演出の残留防止**: 勝利・再戦・世代切替時に被弾数字、攻撃エフェクト、キャラクターの揺れ、使用中カードの発光、テロップを初期化。
2. **敵のカード行動を1枚ずつ表示**: カードが光る → 「敵が『斬撃』を使用！」のテロップ → 効果・SE → **約2秒表示** → 消灯 → 次へ。最後の敵カードも消灯し、プレイヤーターンに発光を持ち越さない。
3. **演出速度切替**: 画面右上の **「演出 通常 / 高速」** で切替。通常は1枚約2秒、高速は約0.5秒。戦闘結果やAIの判断は変わらない。
4. **スマホの情報配置**: 上から「敵HP・敵の手札と戦場」→「敵の能力アイコン・戦闘ログ」→「自分のHP・マナ・カード」。ログは開閉可能で、長いログは内部スクロール。
5. スマホで道中の選択肢を進めた後、次の画面の上部へスクロールを戻す。

### 新要素：切り札カード

通常カードとは異なり、**戦闘中に一度だけ使用できる**カード。デッキの通常枠を使用し、マナも消費。使用済みになると次のターンでも暗転したまま、次の戦闘で再使用可能になる。

- **第一紀「逆境の一撃」**（コスト2）：攻撃力＋失った自分のHPの40%を与える。攻撃力を強化して、傷ついてから撃つ一撃。特殊強化で60%。
- **第二紀「劇毒開花」**（コスト2）：敵が毒状態のときだけ発動可能。攻撃力＋毒の継続ダメージ値×4＋残り持続ターン×2のダメージを即時に与え、毒を消費。特殊強化で毒倍率×5。

各時代の道中に「一度きりの切り札」イベントを追加。**切り札を獲得する／通常カードを獲得する** の2択。ルートは旧5イベントから6イベントへ増えたが、通常デッキ上限5枚（仮）は維持。継承カードは通常デッキと別枠。以前の英雄が切り札をデッキに入れていたら、**次のボスも1戦闘1回だけ使用**できる。必殺技（別枠アクティブ）はまだ未実装。

毒そのものの重ねがけルール・腐蝕の数値は旧版から変更していません。「腐蝕 → 劇毒開花」のコンボが機能するかを検証する版です。

## 素材の差し替え

`assets/asset-map.js` で画像と音声のパスを一括設定。素材は HTML/JS に埋め込まず、差し替え用のファイルとして分離しています。

```text
index.html
assets/
  asset-map.js
  characters/
    guardian.svg       # 第一紀ボス
    era-1.svg          # 第一紀の英雄・第二紀ボス（同じ見た目）
    era-2.svg          # 第二紀の英雄
  backgrounds/
    arena.svg
  cards/
    README.md
  sounds/
    README.md
```

- キャラクター/背景のSVGは同じファイル名の素材に置き換えられます。PNG等に変更するときは `asset-map.js` のパスを書き換えてください。
- カード画像は `GAME_ASSETS.cards` にカードIDをキーにパスを設定。新しいIDは `laststand`（逆境の一撃）/ `venombloom`（劇毒開花）。未設定時は記号アイコンを表示します。
- SEは `GAME_ASSETS.sounds` に設定。空ならWeb Audioの簡易音を再生。

## まだ実装していない要素

必殺技、パッシブ、枷、ボス固有能力、1枚1回の強化制限、周回別強化グレード、カード変異、継承専用の2段階目強化、周回ごとの10倍スケールのインフレ、第三紀以降。これらは先のバージョンで検証。

## 今回のテスト観点

- 敵の行動がカード単位で追えるか／2秒は長すぎないか（右上の高速も比較）。
- スマホでログの場所が分かりやすいか、詳細を開いても操作が妨げられないか。
- 一度きりの切り札に「使いどころ」の判断が生まれるか。
- 第二紀の「腐蝕→劇毒開花」が攻防一体構築と比較してどう感じるか。
